## q01 小红闯关

- 题目链接：https://www.nowcoder.com/questionTerminal/7ce4b75f7a304be481e73bc4dd2705a4
- 核心算法：逆序扫描 + 最大堆。

### 题意转化与关键观察

如果完全不用道具，总耗时是 `sum(a)`。使用一次道具跳过耗时为 `a_i` 的关卡，就等价于从总耗时中减去 `a_i`。因此问题可转成：在道具使用时机合法的前提下，让被跳过关卡的耗时之和最大。

通过第 `k,2k,3k,...` 个关卡后各得到一件道具。边界 `b` 处得到的道具只能跳过编号大于 `b` 的关卡，所以各件道具的候选集合是若干嵌套后缀。

### 推导与正确性

从最靠右的奖励边界开始考虑。它的候选后缀最短、限制最强，显然应选择该后缀中耗时最大的尚未占用关卡。否则，设它选了较小的 `x`，而较大的 `y` 被更早、候选范围更大的道具选中或没有被选；交换 `x,y` 后，两个道具仍合法，节省时间不会下降。

处理完最受限的道具后，向左移动到下一奖励边界，同样的交换论证继续成立。逆序扫描时用最大堆保存当前边界右侧尚未被选走的关卡，正好实现这个贪心。

### 示例演算

例如 `n=7,k=3`，耗时为 `[5,1,9,4,8,2,7]`。

- 越过第 6 关后，右侧只有第 7 关，第一件道具节省 7。
- 越过第 3 关后，剩余右侧候选为第 4、5、6 关，最大耗时是第 5 关的 8。
- 总耗时为 36，共节省 15，最少耗时为 `36-15=21`。

### 算法步骤

1. 用 64 位整数求 `total=sum(a)`。
2. 建立空的最大堆和 `saved=0`。
3. 令 `i` 从 `n` 递减到 1：
   - 若 `i mod k=0` 且堆非空，先弹出堆顶并加到 `saved`；
   - 再把 `a_i` 放入堆。
4. 输出 `total-saved`。

### 边界与实现注意

- 必须“先取堆、后加入 `a_i`”：刚通过第 `i` 关获得的道具不能反过来跳过第 `i` 关。
- 若 `i=n` 且它是奖励边界，右侧为空，这件道具无法使用。
- `k>n` 时没有可用道具，答案就是总耗时。
- 最大总耗时可达 `10^10`，必须使用 64 位整数。

### 复杂度与约束对应

- 时间复杂度：`O(n log n)`。
- 空间复杂度：`O(n)`。
- `n≤10^5`，堆操作数量为线性次，可以满足时限。

## q02 小苯的子串删除

- 题目链接：https://www.nowcoder.com/questionTerminal/40de22ffa68740cca2193b3c9aa8fc7a
- 核心算法：模 3 前缀和计数。

### 题意转化与关键观察

十进制整数能被 3 整除，当且仅当各位数字之和能被 3 整除。设全部数位和为 `S`，删除区间的数位和为 `D`，则剩余数字合法等价于：

`(S-D) mod 3=0`，也就是 `D mod 3=S mod 3`。

于是无需处理真正的数字串拼接，只需统计数位和余数符合条件的连续区间。

### 从定义到前缀公式与正确性

令 `P[i]` 为前 `i` 个数位之和，`P[0]=0`。删除 `[l,r]` 的数位和是：

`D=P[r]-P[l-1]`。

令 `target=S mod 3`，合法条件变为：

`P[l-1] mod 3 = (P[r]-target) mod 3`。

扫描右端点 `r` 时，只需知道此前三种前缀余数各出现了几次。每一对满足条件的前缀与一个删除区间一一对应，所以计数既不会遗漏也不会重复。

### 示例演算

字符串 `1233` 的数位和是 9，`target=0`。前缀余数依次为：

`P[0..4] mod 3 = [0,1,0,0,0]`。

余数 0 出现 4 次，可任选两个前缀形成 `C(4,2)=6` 个删除区间；余数 1 只出现一次。原串本身也能被 3 整除，所以“不删除”再加 1，答案为 7。全部删除对应 `P[4]-P[0]`，已经包含在 6 个区间中。

### 算法步骤

1. 扫描字符串求 `S`，并令 `target=S mod 3`。
2. 初始化 `cnt=[1,0,0]`，表示空前缀余数为 0；令 `prefix=0, ans=0`。
3. 从左到右读每个数位：
   - 更新 `prefix`；
   - 求需要的左前缀余数 `need=(prefix-target) mod 3`；
   - `ans += cnt[need]`；
   - 再令 `cnt[prefix mod 3]++`。
4. 若 `target=0`，为“不删除”方案令 `ans++`。
5. 输出 `ans`。

### 边界与实现注意

- 语言中的负数取模可能仍为负，`need` 要规范化到 0、1、2。
- 全部删除按题意把剩余串视为 0，已经作为普通区间统计。
- “最多一次操作”包含不操作，但只有原串合法时不操作才计数。
- 方案数最大约为 `n(n+1)/2+1`；`n=2×10^5` 时超过 32 位，应使用 64 位整数。

### 复杂度与约束对应

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`，只维护 3 个余数计数。
- 线性扫描适合 `n≤2×10^5` 和 1 秒限制。

## q03 小红的完全平方数

- 题目链接：https://www.nowcoder.com/questionTerminal/8e83151b7a5b4e1196eb9aa4c4ff7d95
- 核心算法：平方自由核 + 频次统计。

### 题意转化与关键观察

把正整数质因数分解为 `a=∏p^{e_p}`。只保留指数为奇数的质因子之积，记作平方自由核：

`kernel(a)=∏_{e_p 为奇数}p`。

乘积 `a_i a_j` 是完全平方数，当且仅当每个质因子的总指数都是偶数，也就等价于：

`kernel(a_i)=kernel(a_j)`。

所以“任意两数乘积都是平方数”等价于数组中所有元素的平方自由核完全相同。

### 最少操作推导与正确性

一次操作可以给某个元素乘任意正整数，因此可以一次性翻转任意若干质因数指数的奇偶性。也就是说，一个元素的核可以在一次操作内改成任意目标核。

若最终目标核选为 `t`，当前核已经等于 `t` 的元素无需操作，其余每个元素恰好操作一次。因此代价为：

`n-frequency[t]`。

选择出现次数最多的核使代价最小，答案就是 `n-maxFrequency`。这同时给出下界和构造方式，因此是最优解。

### 示例演算

数组 `[12,75,18,8]`：

- `12=2²×3`，核为 3；
- `75=3×5²`，核为 3；
- `18=2×3²`，核为 2；
- `8=2³`，核为 2。

核 2 和 3 都出现两次，任选一个作为目标都只需修改另外两个元素，答案为 2。比如 `12×75=900` 已经是完全平方数。

### 算法步骤

1. 令 `M=max(a_i)`，筛出 `1..M` 的最小质因子 `spf`。
2. 对每个 `a_i`：
   - 按 `spf` 分解；
   - 统计每个质因子的指数，只把奇数次的质因子乘入 `kernel`；
   - 在哈希表中增加该核的频次并维护最大频次。
3. 输出 `n-maxFrequency`。

### 边界与实现注意

- 数字 1 没有质因子，核定义为 1。
- 构造目标乘数时只需补齐指数奇偶性，不需要真的计算或输出该乘数。
- 核不会超过原数的平方自由部分，在本题范围内普通整数足够；频次使用整数。
- 若所有核相同，答案为 0；若 `n=1`，条件 vacuously 成立，答案同样为 0。

### 复杂度与约束对应

设 `M=max(a_i)≤10^6`：

- 时间复杂度：筛表 `O(M log log M)`，分解全部元素约 `O(n log M)`。
- 空间复杂度：`O(M+n)`。
- 预处理到 `10^6` 后，每个数只需沿最小质因子链处理，适合 `n≤10^5`。
