## q01 牛牛与切割机

- 题目链接：https://www.nowcoder.com/questionTerminal/cda06078a54142d29da7adc3b9ad5880
- 核心算法：总和 + 前缀和枚举切点。

### 题意转化与关键观察

切一刀后两段都必须非空，因此切点只有 `p=1..n-1`。设数组总和为 `S`，前 `p` 个元素之和为 `P_p`，那么右段和是 `S-P_p`，切割代价直接写成：

`cost(p)=P_p(S-P_p)`。

题目允许负数，乘积可能为负，也没有单调性可利用；枚举所有合法切点是最稳妥的线性方案。

### 推导与正确性

任意合法切割与一个唯一的 `p∈[1,n-1]` 一一对应。前缀和给出的左右段和严格等于该切割的定义，因此算法计算了每一种切割的真实代价。对全部代价取最小，不可能遗漏更优方案，故结果正确。

不要套用“让两段和尽量接近”的思路：那通常用于最小化差值，或在非负条件下讨论乘积最大值；本题要最小化乘积且元素可为负。

### 示例演算

数组 `[-5,10,-2]`，总和 `S=3`：

- `p=1`：左和 -5，右和 8，代价 -40。
- `p=2`：左和 5，右和 -2，代价 -10。

最小值为 -40。这个例子也说明答案不一定非负。

### 算法步骤

1. 读入并保存数组，同时用 64 位整数求总和 `S`。
2. 初始化 `prefix=0`、`answer=+∞`。
3. 对 `p=1..n-1`：
   - `prefix += a_p`；
   - `cost=prefix×(S-prefix)`；
   - 用 `cost` 更新答案。
4. 输出答案。

### 边界与实现注意

- 循环只到 `n-1`，否则右段为空。
- `n=2` 时只有一个合法切点。
- 前缀和绝对值可达 `10^9`，乘积可达 `10^18` 量级，必须使用 64 位整数。
- 若边读边求总和，第二遍仍需要元素，所以通常保存数组；额外空间为 `O(n)`。

### 复杂度与约束对应

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`，保存输入数组。
- `n≤10^6` 且时限 1 秒，应使用线性扫描和高效输入，不能做二次枚举。

## q02 字符串排序

- 题目链接：https://www.nowcoder.com/questionTerminal/9ad2f07d6eb74a6e935e54279b29910d
- 核心算法：自定义字典序比较器。

### 题意转化与关键观察

第一行给出的是一套新的字母顺序。建立 `rank[c]` 表示字母 `c` 在该顺序中的位置后，题目排序规则就变成普通字典序，只是字符大小由 `rank` 而不是 ASCII 决定。

比较两个字符串时，从左到右找第一个不同字符；若找到，就比较对应 `rank`。若直到较短串结尾仍相同，较短串是前缀，应排在前面。

### 正确性说明

该比较过程逐条实现题面定义：

- 第一个不同字符存在时，更早字符完全相同，排序只由该位置的自定义大小决定。
- 不存在不同字符时，一个串是另一个的前缀，前缀规则决定较短者在前。

因此比较器对任意两个字符串给出的关系与题面完全一致。把它交给通用排序，输出序列自然满足所有两两顺序要求。

### 示例演算

假设字母顺序以 `z,y,x,...,a` 开头，待排字符串为 `["za","z","ya"]`：

- `"z"` 是 `"za"` 的前缀，所以 `"z"` 在前。
- `z` 的自定义排名早于 `y`，所以 `"za"` 也在 `"ya"` 前。

结果为 `["z","za","ya"]`。

### 算法步骤

1. 扫描 26 字母顺序串，令 `rank[order[i]]=i`。
2. 定义比较函数 `less(s,t)`：
   - 枚举 `i=0..min(|s|,|t|)-1`；
   - 遇到不同字符时返回 `rank[s[i]]<rank[t[i]]`；
   - 若公共部分完全相同，返回 `|s|<|t|`。
3. 用该比较器排序字符串数组。
4. 按排序结果逐行输出。

### 边界与实现注意

- 前缀判断必须在逐字符循环结束后进行。
- 完全相同的字符串比较结果应为 false，不能同时认为彼此“小于”。
- 题面允许长度上限为 1000；若实现能读到空串，空串是所有非空串的前缀。
- `rank` 用固定 26 长度数组即可。

### 复杂度与约束对应

设最长字符串长度为 `L≤1000`：

- 时间复杂度：最坏 `O(n log n·L)`。
- 空间复杂度：排序辅助空间 `O(n)`，不计字符串存储。
- `n≤1000`，即使很多字符串拥有长公共前缀也可接受。

## q03 牛牛的糖果树

- 题目链接：https://www.nowcoder.com/questionTerminal/2bd533b4fd094ae6a0e46ff3db8415af
- 核心算法：树形 DP 合并颜色频次。

### 题意转化与关键观察

选择节点 `u` 就是选择以它为根的整棵子树。设该子树中颜色 `c` 出现 `cnt[u][c]` 次，令最大频次为 `mx`：

- 所有 `cnt[u][c]=mx` 的颜色都被整类扔掉；
- 其余颜色的每颗糖都参与异或。

同一个整数异或偶数次为 0、奇数次等于自身，所以剩余异或值只需要关注频次奇偶：

`value(u)=XOR 所有满足 cnt[u][c]≠mx 且 cnt[u][c] 为奇数的 c`。

### DP 推导与正确性

颜色值不超过 1000，可为每个节点保存完整频次数组。后序 DFS 时：

`cnt[u][c]=[color[u]=c]+Σ_{v 是 u 的孩子}cnt[v][c]`。

孩子子树互不相交，加上当前节点恰好组成 `u` 的子树，因此该合并式准确。对合并后的频次按题意先找 `mx`，再过滤最高频颜色并利用异或奇偶性，得到的就是选择该子树时的真实收益。枚举所有 `u` 取最大即为答案。

### 示例演算

节点颜色为 `[1,1,2,2]`，边为 `1-2,2-3,2-4`，根是 1。

- 子树 2 包含颜色频次：1 出现 1 次，2 出现 2 次。
- 最大频次是 2，所以颜色 2 的两颗糖全部扔掉。
- 剩下一颗颜色 1，异或值为 1。
- 根子树中颜色 1、2 都出现 2 次，并列最高，全部扔掉，值为 0。

因此所有子树中的最大值是 1。

### 算法步骤

1. 建无向邻接表，从根节点 1 开始 DFS，并传入父节点避免回边。
2. 访问完所有孩子后：
   - 令 `cnt[u][color[u]]++`；
   - 对每个孩子 `v`、每种颜色 `c=1..1000`，累加 `cnt[v][c]`。
3. 扫描 `cnt[u]` 求最大频次 `mx`。
4. 再扫描颜色：若频次不等于 `mx` 且为奇数，则异或该颜色。
5. 用当前子树值更新全局最大答案。

### 边界与实现注意

- 多个颜色并列最高频时必须全部排除，不能只扔掉其中一个。
- 单节点子树唯一颜色频次最高，会被扔掉，值为 0。
- 频次为 0 的“未出现颜色”不能成为最高频，因为子树非空，`mx≥1`。
- `n≤1000`，递归 DFS 通常可行；也可用迭代后序避免语言栈限制。

### 复杂度与约束对应

令颜色上限 `C=1000`：

- 时间复杂度：`O(nC)`，每条父子关系合并一个长度 `C` 的数组。
- 空间复杂度：`O(nC)`。
- 最大约一百万个计数单元和同量级合并，符合 `n,C≤1000`。
