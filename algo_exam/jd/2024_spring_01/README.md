## q01 不同字符

- 题目链接：https://www.nowcoder.com/questionTerminal/12abaf3aaa944c768f3e64444592f63a
- 核心算法：固定字符集存在性统计。

### 题意转化与关键观察

题目只问“出现过多少种字符”，同一字符出现多少次不影响答案。输入字符范围固定为大小写英文字母和数字，共 62 种，因此可以把每种字符是否出现记录为布尔状态，而不需要排序字符串或保存频次。

大小写敏感，`A` 与 `a` 是不同字符；数字也按字符身份统计。

### 正确性说明

扫描时第一次看到字符 `c`，把 `seen[c]` 从 false 改成 true 并让答案加一；之后再次遇到 `c` 时状态已经为 true，不再增加。

每种实际出现的字符恰好在第一次出现时贡献 1，未出现字符永不贡献，因此最终计数与不同字符集合大小完全相同。

### 示例演算

字符串 `"aA1a"`：

- 第一个 `a`：首次出现，计数 1；
- `A`：与小写不同，计数 2；
- `1`：首次出现，计数 3；
- 最后一个 `a`：已经出现，计数不变。

答案为 3。

### 算法步骤

1. 建立覆盖 ASCII 字符的布尔数组 `seen`，初始全为 false。
2. 令 `answer=0`。
3. 从左到右扫描字符串：
   - 若 `seen[ch]` 为 false，置为 true 并令 `answer++`；
   - 否则跳过。
4. 输出 `answer`。

### 边界与实现注意

- `n=1` 时答案为 1。
- 不要把字符串转成统一大小写。
- 输入只含单字节字母和数字，按字节遍历即可；无需 Unicode 解码。
- 也可用集合实现，但固定布尔数组常数更小。
- 若只开 62 个状态，可依次把 `0..9`、`A..Z`、`a..z` 映射到三个互不重叠的下标区间；映射必须保持大小写和数字身份的一一对应。
- 题目给出 `n`，可在调试时核对字符串长度，但计数逻辑本身只需扫描实际字符串。

### 复杂度与约束对应

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`，字符集大小固定。
- `n≤1000`，一次扫描足够。

## q02 调皮的依依

- 题目链接：https://www.nowcoder.com/questionTerminal/40ebefcc3dfa42cbb482ec1ef1a38b0e
- 核心算法：结构校验 + 等差数列求缺失值。

### 题意转化与关键观察

从升序序列 `1,2,...,n` 恰好擦掉一个数字后：

1. 剩余数量必须是 `n-1`；
2. 所有数字仍在 `[1,n]`；
3. 顺序仍严格递增且没有重复；
4. 与完整序列相比只缺一项。

只有在这些条件都验证后，才能利用总和求缺失值。单独使用和式会误判，例如乱序或重复输入可能碰巧拥有相同总和。

### 公式与正确性

完整序列总和是 `n(n+1)/2`。若验证确认剩余序列确实是完整集合删掉一个数，缺失值唯一且为：

`missing=n(n+1)/2-Σa_i`。

必要性显然来自擦除操作。充分性方面，长度为 `n-1`、元素范围合法且严格递增时，剩余数互异；若计算出的 `missing` 在 1 到 `n` 且未出现，那么这些数与它合并后恰好构成大小为 `n` 的集合 `{1..n}`，所以确实可由一次擦除得到。

### 示例演算

`n=5,m=4`，剩余 `[1,2,4,5]`。结构合法，总和为 12，完整和为 15，所以缺失 3，输出 Yes 和 3。

若剩余为 `[1,2,2,5]`，即使数量正确，也因重复且不严格递增而不可能来自擦除，必须输出 No。

### 算法步骤

1. 若 `m≠n-1`，直接判 No。
2. 扫描剩余序列：
   - 检查每项在 `[1,n]`；
   - 检查从第二项起严格大于前一项；
   - 累加总和。
3. 计算 `missing=n(n+1)/2-sum`。
4. 检查 `missing` 在 `[1,n]` 且不在剩余序列中。
5. 全部通过则输出 Yes 和 `missing`，否则输出 No。

也可用期望值指针从 1 扫到 `n`，与输入逐项匹配，并只允许跳过一次。

### 边界与实现注意

- 被擦除的可能是 1 或 `n`。
- 黑板原序列是升序，输入顺序也必须保持这一事实。
- 任一验证失败时只输出 No，不输出第二行。
- `n≤1000`，整数和不会溢出；使用 64 位公式可避免把写法绑定在当前范围。

### 复杂度与约束对应

- 时间复杂度：`O(n)`。
- 空间复杂度：若顺序扫描并同时确认缺失项，可为 `O(1)`；保存输入则为 `O(n)`。
- 线性校验能完整覆盖所有非法形态。

## q03 墙壁划线

- 题目链接：https://www.nowcoder.com/questionTerminal/fbae28533ca04bd0ba088329cb46210d
- 核心算法：最大公约数 + 容斥计数。

### 题意转化与关键观察

瓷砖实际尺寸 `x×y` 只会缩放墙面坐标，不改变对角线穿过多少条网格线，所以答案只依赖横、纵瓷砖数 `a,b`。

先统计一条对角线与所有网格边界的不同交点，再将两条对角线结果用容斥合并。

### 单条对角线公式推导

墙面共有 `a+1` 条竖直网格线、`b+1` 条水平网格线。一条对角线与每条线各交一次，初步得到 `a+b+2` 次。

若交点恰好是网格顶点，它同时属于一条横线和一条竖线，被计算两次。对角线经过的网格顶点数（含两个端点）为 `gcd(a,b)+1`，每个应减去一次。因此单条对角线的不同交点数是：

`a+b+2-(gcd(a,b)+1)=a+b-gcd(a,b)+1`。

两条对角线彼此只在墙面中心相交。中心在竖直网格线上当且仅当 `a` 为偶数，在水平网格线上当且仅当 `b` 为偶数；只要二者至少一个为偶数，中心就同时属于两条“对角线与边界”的交点集合，需要再减 1。

### 正确性与最终公式

横纵网格线覆盖全部瓷砖边界，单线容斥已经消除了顶点重复；两条对角线除中心外没有公共点，所以第二次容斥只需判断中心一次。最终：

`answer=2(a+b-gcd(a,b)+1)-[a 为偶数或 b 为偶数]`。

### 示例演算

`a=2,b=3`，`gcd=1`。单条对角线有 `2+3-1+1=5` 个交点，两条共 10。因为 `a` 是偶数，中心位于竖直网格线上并被重复一次，答案为 9，与题目示例一致。

`a=b=2` 时单线 3 个，两条在中心重复，答案 `2×3-1=5`。

### 算法步骤

1. 读入 `a,b,x,y`；`x,y` 不参与计数。
2. 用欧几里得算法求 `g=gcd(a,b)`。
3. 令 `answer=2×(a+b-g+1)`。
4. 若 `a mod 2=0` 或 `b mod 2=0`，令 `answer--`。
5. 输出答案。

### 边界与实现注意

- 外墙四条边也是瓷砖边界，四个角必须计入。
- 网格顶点是一个几何点，不能因同时落在横线和竖线上重复计数。
- 当 `a,b` 都为奇数时，两条对角线虽在中心相交，但中心不在瓷砖边界上，不属于统计对象。
- 具体瓷砖尺寸不会改变比例关系。

### 复杂度与约束对应

- 时间复杂度：`O(log min(a,b))`，来自欧几里得算法。
- 空间复杂度：`O(1)`。
- 无需建立实际网格或模拟直线。

## q04 Y型树

- 题目链接：https://www.nowcoder.com/questionTerminal/444ca6d8ab1c416e9729392d377b4fa8
- 核心算法：三部分整数拆分闭式 + 安全取模。

### 题意转化与关键观察

Y 型树有唯一一个度为 3 的中心，其余节点形成从中心伸出的三条非空链。设三条臂长为 `x,y,z`。顶点无标号、三条臂没有顺序，所以规定：

`1≤x≤y≤z`，且 `x+y+z=N-1`。

于是树计数与把 `m=N-1` 拆成恰好三个正整数部分的无序方案数完全等价。

### 从枚举到闭式公式与正确性

固定最小部分 `x`，它最多为 `floor(m/3)`。剩余满足：

`x≤y≤(m-x)/2`，而 `z=m-x-y` 自动满足 `z≥y`。

所以固定 `x` 的方案数是：

`floor((m-x)/2)-x+1`。

对 `x=1..floor(m/3)` 求和，并按 `m` 的奇偶余数化简，可得到经典闭式：

`part3(m)=floor((m²+3)/12)`，

也就是与 `m²/12` 最近的整数。

每组三臂长度唯一决定一个 Y 型树，任意 Y 型树也唯一还原出排序后的三臂长度，所以这个拆分计数与树计数是一一对应的。

### 示例演算

`N=7` 时 `m=6`。三个正整数的无序拆分为：

- `1+1+4`；
- `1+2+3`；
- `2+2+2`。

共 3 种。闭式给出 `floor((6²+3)/12)=floor(39/12)=3`。

### 算法步骤与大数取模推导

`N≤10^18`，不能直接计算 `m²`。写成 `m=12q+r`，其中 `0≤r<12`：

`floor((m²+3)/12)=12q²+2qr+floor((r²+3)/12)`。

实现步骤：

1. 令 `m=N-1`，`q=m/12`，`r=m mod 12`。
2. 在模 `MOD=10^9+7` 下计算 `12q²` 和 `2qr`。
3. 小整数项 `floor((r²+3)/12)` 可直接整除计算。
4. 三项相加后对 `MOD` 取模并输出。

### 边界与实现注意

- `N=4` 时只有臂长 `1,1,1`，答案为 1。
- 三条臂没有编号，不能计算有序三元组，否则会重复 3 或 6 倍。
- 计算 `q² mod MOD` 时先令 `q%=MOD`，并安排乘法取模顺序，避免先形成 `12q²` 的 64 位溢出。
- 不能把 `floor((m²+3)/12)` 简单改成“模意义下乘 12 的逆元”，因为取整发生在取模之前；按 12 分解保留了精确商。

### 复杂度与约束对应

- 时间复杂度：`O(1)`。
- 空间复杂度：`O(1)`。
- 闭式和余数分解直接支持 `N=10^18`，无需循环到 `N`。
