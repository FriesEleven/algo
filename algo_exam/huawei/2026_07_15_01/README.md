## q01 小红的开放水槽

- 题目链接：https://www.nowcoder.com/questionTerminal/f875b5aa20114794882f1bc2e186d15a
- 核心算法：前缀最高挡板 + 后缀最高挡板。

### 题意转化与关键观察

有 `n` 块竖直挡板，真正需要求水量的是它们之间的 `n-1` 个单位底面积槽位。对第 `i` 和第 `i+1` 块挡板之间的槽位，水要向左流出必须越过左侧某块挡板，向右流出也必须越过右侧某块挡板。

左侧能形成的最高封闭高度是 `max(h_1..h_i)`，右侧对应 `max(h_{i+1}..h_n)`。较低的一侧先溢流，所以稳定水位是两者的最小值。

### 公式与正确性

定义：

- `leftMax[i]=max(h_1..h_i)`；
- `rightMax[i]=max(h_i..h_n)`。

槽位 `i` 的水量为：

`water_i=min(leftMax[i],rightMax[i+1])`。

这是上界：水位再高就会越过较低侧的最高挡板并流向开口。这也是可达到的下界：在该高度以下，左右两侧都至少存在一块不低于水位的挡板，水不会泄出。因此公式恰好是稳定水位。

注意这不是常见柱状图接雨水的“水位减柱高”：这里挡板之间的槽位从底部开始，挡板本身不占槽位底面积。

### 示例演算

`h=[3,1,4]`：

- 第 1、2 块挡板之间：左最高为 3，右侧最高为 4，水位为 3。
- 第 2、3 块挡板之间：左侧最高仍为 3，右侧最高为 4，水位也为 3。

两个槽位底面积都为 1，总水量为 `3+3=6`。

### 算法步骤

1. 从右向左预处理 `rightMax[i]`。
2. 令 `left= h_1, answer=0`。
3. 对槽位 `i=1..n-1`：
   - 更新/保持 `left=max(left,h_i)`；
   - 累加 `min(left,rightMax[i+1])`。
4. 输出总和。

### 边界与实现注意

- `n=1` 时没有槽位，答案为 0。
- 两端是开口，不是额外的无限高墙；公式只使用实际挡板。
- 最大总量约为 `(n-1)×30000`，32 位虽接近可用范围，统一使用 64 位累加更安全。
- 下标要区分“挡板位置”和“挡板之间的槽位”。

### 复杂度与约束对应

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`，保存后缀最大值。
- `n≤30000`，两次线性扫描远低于时限。

## q02 小红的多频段组合

- 题目链接：https://www.nowcoder.com/questionTerminal/ecc88f0498774544a6e19be3310e30d6
- 核心算法：频段状态压缩 + 限深回溯。

### 题意转化与关键观察

一个方案是否合法只取决于已选择的载波数和频段集合：

- 同一频段最多选一条载波；
- 冲突频段不能同时出现；
- 总数不超过 `K≤8`。

`N≤25`，不能盲目枚举所有大规模组合，但枚举大小不超过 8 的子集是可行的。把候选载波涉及的频段压缩成不超过 25 个编号，用位掩码维护当前已选频段；每个频段再预处理一个冲突掩码。

### 状态与正确性

回溯状态包含 `pos`、`chosenCount`、`selectedBands`、`bandwidthSum` 和升序编号列表。对第 `pos` 条载波恰好有两种决策：不选，或在满足约束时选择。

选择条件是：

1. `chosenCount<K`；
2. 当前频段位不在 `selectedBands` 中；
3. `conflict[currentBand] AND selectedBands = 0`。

回溯树对每条载波都做一次二选一，因此每个子集恰好出现一次；上述三个条件又与题目约束完全等价。于是检查所有可达状态并取最大带宽必然得到最优方案。按编号递增搜索，候选编号列表天然有序，可以直接做字典序比较。

### 示例演算

有 4 条载波，`K=2`：

| 编号 | 频段 | 带宽 |
|---|---|---:|
| 0 | A | 5 |
| 1 | B | 6 |
| 2 | A | 8 |
| 3 | C | 4 |

设 B 与 C 冲突。`{0,2}` 因频段重复不合法，`{1,3}` 因冲突不合法；`{1,2}` 合法且带宽为 14，是最优方案，输出编号 `1 2`。

### 算法步骤

1. 把所有频段名转为统一小写，再压缩成整数编号。
2. 根据冲突对建立对称的 `conflict[band]` 位掩码。
3. 从编号 0 开始 DFS：
   - 先递归“不选当前载波”；
   - 若三个选择条件满足，则加入当前编号、频段位和带宽后递归；
   - 回溯撤销选择。
4. 每到一个状态都可更新最佳答案，因为允许“至多 K 个”。
5. 带宽更大时替换答案；带宽相同时按标准序列字典序保留更小的编号列表。

伪代码核心为：

    dfs(pos):
        updateBest()
        if pos == N: return
        dfs(pos + 1)
        if canChoose(pos):
            choose(pos)
            dfs(pos + 1)
            undo(pos)

### 边界与实现注意

- 频段名比较不区分大小写；载波表和冲突表必须采用同一规范化方式。
- 冲突关系是无向的，需要双向记录。
- 冲突对中不出现在候选载波里的频段无需占状态位，因为它永远不会被选中。
- 带宽都为正，但仍要在中间状态更新答案，以正确表达“至多 K 个”。
- 字典序比较时使用升序编号序列；一方是另一方前缀时，较短者更小。

### 复杂度与约束对应

令 `S=Σ_{i=0..K} C(N,i)`：

- 时间复杂度：保守上界 `O(NS)`；每个大小不超过 `K` 的候选子集只会被形成一次，回溯循环与字典序比较的额外因子都不超过 `N`。
- 空间复杂度：`O(N+K)`，包括递归栈和当前方案。
- 在最大约束 `N=25,K=8` 下，`S=1,807,781`，并配合 O(1) 位运算判冲突，可以通过。

## q03 小红的目标串补全

- 题目链接：https://www.nowcoder.com/questionTerminal/8565a9bfc1d44ba8ac481ab1f3591301
- 核心算法：最长公共子序列 DP。

### 题意转化与关键观察

只能向 `S` 中插入字符，原有字符的相对顺序不能改变。若最终让 `T` 成为新串的子序列，那么 `T` 中有一部分字符可以由 `S` 的原字符承担；这些被复用字符在 `S` 和 `T` 中都必须保持相对顺序，所以它们组成两串的公共子序列。

能复用的最多字符数就是 `LCS(S,T)`，其余目标字符必须插入。

### 下界、构造、DP 状态与正确性

任何方案最多复用 `LCS` 个字符，因此至少要插入 `|T|-LCS` 个字符。反过来，取一条最长公共子序列，把 `T` 中不属于这条匹配的字符依次插到相邻匹配字符之间，就能用恰好这么多次插入完成。因此：

`answer=|T|-LCS(S,T)`。

定义 `dp[i][j]` 为 `S` 前 `i` 个字符和 `T` 前 `j` 个字符的 LCS 长度：

- 字符相等：`dp[i][j]=dp[i-1][j-1]+1`；
- 字符不同：`dp[i][j]=max(dp[i-1][j],dp[i][j-1])`。

每一情况都对应“使用这一对相等字符”或“至少舍弃一侧末字符”，所以转移完备。

### 示例演算

`T="abc"`，`S="acx"`。两串最长公共子序列是 `"ac"`，长度为 2，所以最少插入 `3-2=1` 个字符。把 `b` 插在 `S` 的 `a,c` 之间得到 `"abcx"`，`"abc"` 已是其子序列。

### 算法步骤

1. 为节省空间，让较短字符串对应 DP 的列。
2. 初始化长度为 `shortLen+1` 的上一行和当前行数组为 0。
3. 枚举长串位置 `i`，再枚举短串位置 `j`，按上述两种情况转移。
4. 每行结束后交换滚动数组。
5. 令 `lcs=lastRow[shortLen]`，输出 `|T|-lcs`。

### 边界与实现注意

- `S` 中没有参与匹配的字符可以原样保留，因为题目只要求 `T` 是子序列。
- 插入的字符自然取自 `T` 中未匹配的位置，满足字符集合限制。
- 两串相同且 `T` 已是 `S` 的子序列时答案为 0。
- 滚动数组覆盖前要保留完整上一行，避免把本行值误当成上一行。

### 复杂度与约束对应

- 时间复杂度：`O(|S||T|)`。
- 空间复杂度：`O(min(|S|,|T|))`。
- 最大状态数 `2500²=6.25×10^6`，滚动 DP 可以稳定通过。
