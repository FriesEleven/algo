# Algorithm Notes

本文件汇总这一批笔试中各道编程题的解题思路，不包含完整代码或 IO 模板。

## q01 小红的动态专家路由

- 题目链接：https://www.nowcoder.com/questionTerminal/da5b0f10208143a8ac64e680b7f07f89
- 核心算法：逐任务候选排序 + 按序模拟。

### 题意转化与关键观察

题目分成两个严格顺序的阶段：

1. 对当前任务，仅依据评分选出前 `K` 位专家，评分相同时编号小者优先。
2. 再检查这 `K` 位专家的当前负载；未满则负载加一，已满则本次分配丢弃。

容量不会改变第一阶段的候选名单。尤其不能在某位候选已满时，临时把第 `K+1` 名专家补进来。任务又必须按编号顺序处理，所以这是一个确定性的在线模拟。

### 正确性推导

对每个任务，排序规则唯一确定一个长度为 `K` 的候选集合。给定处理此前任务后的负载数组，对每位候选执行“`load[e]<C` 则加一，否则不变”，也唯一确定处理后的负载。

从任务 0 开始归纳：算法在每一步都与题面执行完全相同的排序和容量判断，因此处理完任意前缀后的负载都与真实过程一致；最终负载及平方和自然正确。

### 示例演算

`N=2,E=3,K=2,C=1`，两行评分为：

- 任务 0：`[5,5,1]`，同分时编号小，候选是专家 0、1，负载变成 `[1,1,0]`。
- 任务 1：`[9,8,7]`，候选仍是专家 0、1，但两者都已满，因此两次分配都丢弃；专家 2 不补位。

最终平方和是 `1²+1²+0²=2`。

### 算法步骤

1. 初始化 `load[0..E-1]=0`。
2. 对任务 `i=0..N-1`：
   - 建立专家编号数组 `0..E-1`；
   - 按“`score[i][e]` 降序、`e` 升序”排序；
   - 枚举排序后的前 `K` 个编号；
   - 若 `load[e]<C`，令 `load[e]++`。
3. 用 64 位整数累加 `Σ load[e]²`。
4. 输出平方和及负载数组。

### 边界与实现注意

- 分数相同必须按专家编号升序，排序比较器要形成严格弱序。
- 已满候选不会触发补位。
- `C=0` 时所有分配都丢弃。
- `N×E≤5×10^5`，评分矩阵可读入后处理，也可逐行处理以节省内存。
- 平方和使用 64 位整数。

### 复杂度与约束对应

- 时间复杂度：`O(NE log E)`。
- 空间复杂度：额外 `O(E)`，复用专家编号数组。
- `E≤100` 且 `NE≤5×10^5`，全排序最多只是数百万次比较。

## q02 小红的流水线阶段划分

- 题目链接：https://www.nowcoder.com/questionTerminal/026580fd0ddc40b39e56a41b6525ce80
- 核心算法：连续分段 DP + 单调队列优化。

### 题意转化与状态定义

划分必须恰好得到 `p` 个非空连续段。令 `prefix[i]` 为前 `i` 层计算时间之和，定义：

`dp[g][i] = 前 i 层恰好划成 g 段的最小通信开销`。

若最后一段是第 `m+1..i` 层，则前 `m` 层已分成 `g-1` 段，并在第 `m` 层后产生一次通信开销。转移为：

`dp[g][i] = min(dp[g-1][m]+comm[m])`，

其中 `g-1≤m<i` 且 `prefix[i]-prefix[m]≤T`。

基础状态是 `dp[1][i]=0`，前提为 `prefix[i]≤T`。

### 单调队列推导与正确性

对固定 `g`，候选 `m` 的值：

`value[m]=dp[g-1][m]+comm[m]`

与右端点 `i` 无关。随着 `i` 递增，因为层时间全为正，满足最后一段和不超过 `T` 的 `m` 构成一个向右滑动的区间。

维护候选下标按 `value` 单调递增：

- 队首若已不满足 `prefix[i]-prefix[m]≤T`，以后也永远不满足，可以弹出。
- 插入新候选时，队尾若 `value` 不小于新值，则它更贵且更早失效，被新候选完全支配，可以弹出。
- 此后队首就是当前合法转移的最小值。

DP 转移枚举了最后一个切点，覆盖所有合法划分；单调队列只删除不可能再成为最优的候选，因此优化不改变答案。

### 示例演算

`n=5,p=3,T=10`，层时间 `[2,4,6,3,7]`，所有切分开销均为 1。

划分 `[2,4] | [6,3] | [7]` 的三段和分别为 6、9、7，合法；切点在第 2、4 层后，总通信开销为 2。因为恰好三段必有两个切点，且每个开销都是 1，所以 2 也是下界，答案就是 2。

### 算法步骤

1. 求前缀和；不可达值设为足够大的 `INF`。
2. 初始化第一层 DP：若 `prefix[i]≤T`，令 `prev[i]=0`，否则为 `INF`。
3. 对阶段数 `g=2..p`：
   - 清空单调队列和当前层 `cur`；
   - 对 `i=g..n`：
     1. 新候选切点为 `m=i-1`；若 `prev[m]` 可达，按 `prev[m]+comm[m]` 维护单调队尾后入队；
     2. 从队首删除所有 `prefix[i]-prefix[m]>T` 的候选；
     3. 若队列非空，令 `cur[i]` 等于队首候选值；
   - 交换 `prev,cur`。
4. 最终 `prev[n]` 不可达则输出 -1，否则输出它。

### 边界与实现注意

- `m≥g-1`、`i≥g` 保证每一段非空。
- `comm[m]` 表示第 `m` 层后的切分费，只在 `g≥2` 的转移中加入。
- `p=1` 时答案只能是 0 或 -1，取决于总时间是否不超过 `T`。
- 若任一单层时间大于 `T`，最终必然无解。
- `INF` 加通信费前先判断可达，避免溢出。

### 复杂度与约束对应

- 时间复杂度：`O(pn)`，每个候选每层至多入队、出队一次。
- 空间复杂度：`O(n)`，滚动两层 DP 和一个队列。
- `p,n≤1000`，最多约一百万个状态；朴素 `O(pn²)` 会达到十亿级，必须优化。
