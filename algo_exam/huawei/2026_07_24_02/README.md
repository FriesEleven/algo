## q01 小红的花圃抬高方案

- 题目链接：https://www.nowcoder.com/questionTerminal/aba9790db11f4ed4acd7634b0e9dcf72
- 核心算法：单调可行性 + 二分答案。

### 题意转化与关键观察

固定一个候选最低高度 `H` 后，每个低于 `H` 的花圃都必须补到 `H`，高于它的无需处理。所需土量唯一确定：

`D(H)=Σ max(0,H-h_i)`。

一车可给多个花圃分土，所以运送 `D` 单位土需要的最少车辆数就是 `ceil(D/C)`，不存在按花圃分别向上取整的问题。总成本为：

`cost(H)=U×D(H)+F×ceil(D(H)/C)`。

### 单调性与正确性

当 `H` 增大时，每个 `max(0,H-h_i)` 都不会减小，因此土量、车辆数和总成本都不会减小。可行高度形成连续前缀，可以二分最后一个满足 `cost(H)≤B` 的高度。

对于固定 `H`，`D(H)` 是达到目标不可少的土量；车辆可以任意分配土，`ceil(D/C)` 辆又确实足够运输。因此检查函数给出的成本既是下界又可实现，二分得到的最大可行高度就是答案。

### 示例演算

高度 `[1,3]`，每车容量 `C=3`，运输费 `F=2`，单位土费 `U=1`，预算 `B=8`：

- 检查 `H=4`：需土 `3+1=4`，需 2 车，成本 `4+2×2=8`，可行。
- 检查 `H=5`：需土 `4+2=6`，需 2 车，成本 `6+4=10`，不可行。

所以最大最低高度是 4。

### 算法步骤

1. 令 `low=min(h)`，它一定可行。
2. 取不可行开区间上界 `high=low+B/U+1`；即使不计运输费，把任一最低花圃再提高这么多也已超预算。
3. 当 `low+1<high`：
   - `mid=low+(high-low)/2`；
   - 扫描数组求 `D(mid)`；
   - 若成本不超过 `B`，令 `low=mid`，否则令 `high=mid`。
4. 输出 `low`。

### 边界与实现注意

- `D=0` 时车辆数是 0；不要用可能产生错误含义的固定一车。
- `D>0` 时 `ceil(D/C)=(D+C-1)/C`。
- `B≤10^11`、`n≤10^5`，土量和乘法均使用 64 位整数。
- 累加土量或计算成本时一旦确认超过预算即可提前返回不可行，既加速又避免极端乘法溢出。
- 二分采用“`low` 可行、`high` 不可行”的不变量，避免最后偏一。

### 复杂度与约束对应

- 时间复杂度：`O(n log(B/U+1))`，二分轮数不超过约 37。
- 空间复杂度：`O(1)`，不计输入数组。
- 最坏约四百万次简单累加，适合 `n=10^5`。

## q02 小红的满减购物清单

- 题目链接：https://www.nowcoder.com/questionTerminal/29c6b9c021e748f48d1abe19657fcb77
- 核心算法：全集子集枚举 + 类别位掩码。

### 题意转化与关键观察

每件商品只能买或不买一次，`n≤20`，全部选择方案只有 `2^n≤1,048,576` 个，可以逐一精确检查。

对一个子集，只需维护原价总和 `price`、满意度 `sat` 和类别集合。设类别数为 `types`，折后价是：

- `price-20×floor(price/200)`，若 `types<3`；
- `price-30×floor(price/200)`，若 `types≥3`。

两种优惠互斥，不能叠加。

### 正确性与为何不按当前预算剪枝

DFS 对每件商品做“选/不选”，所以每个购物子集恰好访问一次。叶子处严格按题目公式计算折后价，所有预算内方案都会参与最大满意度比较，因此答案正确。

不能看到中间子集折后价超过预算就立即停止搜索。加入一件便宜商品可能让原价跨过 200 的整数倍或让类别数从 2 变成 3，从而触发更大优惠，折后价可能短暂下降。完整枚举在该约束下更简单可靠。

### 示例演算

预算 `200`，三件商品分别为：

- 类别 1，价格 100，满意度 5；
- 类别 2，价格 100，满意度 6；
- 类别 3，价格 10，满意度 10。

只买前两件：原价 200、两类，减 20，折后价 180，满意度 11。三件全买：原价 210、三类，改为减 30，折后价仍为 180，满意度变成 21。因此类别门槛会实质改变最优选择。

### 算法步骤

1. 以商品编号为递归层，状态维护 `price,sat,categoryMask`。
2. 对当前商品先递归“不选”分支。
3. 再把它的价格、满意度和类别位加入状态，递归“选择”分支。
4. 到 `index=n`：
   - 用位计数得到类别数；
   - 选择对应的每 200 减 20 或减 30 公式；
   - 若折后价 `≤budget`，更新最大满意度。
5. 输出全局最大值。

也可枚举整数掩码，并用最低位递推子集的三项统计量；核心仍是覆盖全部 `2^n` 个方案。

### 边界与实现注意

- 空集合法，折后价和满意度均为 0。
- “至少 3 个不同类别”看类别集合大小，不是商品数量。
- 满减档数按原价的 `floor(price/200)` 计算。
- 商品唯一编号不影响优化，只用于标识。
- 本题数值范围用普通整数足够，但统一使用 64 位计算价格和满意度也更稳妥。

### 复杂度与约束对应

- 时间复杂度：`O(2^n)`；若每个叶子再现算类别位数，也只是常数位运算。
- 空间复杂度：`O(n)`，递归深度为 `n`。
- `n≤20` 时百万级方案可直接枚举，比设计不安全的剪枝更可靠。

## q03 小红的直线寻宝

- 题目链接：https://www.nowcoder.com/questionTerminal/83878451f7d94fd1bcfaf4ea4233c577
- 核心算法：固定回合数的路径 DP。

### 题意转化与关键观察

从位置 0 出发，每一步前进 1、2 或 3，最终恰好到位置 `n`。若 `n>3m`，`m` 回合最多走 `3m` 格，必然无解。

宝物价值都非负。任一路径中若有一步长度大于 1，可以把它拆成两步正长度且都不超过 3 的跳跃，保留原落脚点并新增一个非负收益落脚点，答案不会变差。因此可达时最优方案一定使用尽可能多的回合：

`r=min(m,n)`。

这里 `n` 是最多可能的步数，因为每步至少走 1 格。

### DP 状态、转移与正确性

定义 `dp[t][i]`：恰好用 `t` 回合到达第 `i` 块时，能获得的最大价值。最后一步只能从 `i-1,i-2,i-3` 来，所以：

`dp[t][i]=value[i]+max(dp[t-1][i-1],dp[t-1][i-2],dp[t-1][i-3])`。

基础状态为 `dp[0][0]=0`，其余不可达。转移枚举了最后一步的全部三种长度；任一合法路径删去最后一步都会落入一个前驱状态，反之任一可达前驱加上该步都合法，所以由归纳可知 DP 精确。

### 示例演算

`n=5,m=3`，价值为 `[1,2,1,1,3]`。可达且 `r=3`。

- 一条最优路线是 `0→2→3→5`；
- 三次落脚获得 `2+1+3=6`。
- 例如 `0→3→5` 只用两回合、收益 4；把第一步拆出位置 2 后收益不会下降。

因此答案为 6。

### 算法步骤

1. 若 `n>3m`，输出 -1。
2. 令 `r=min(m,n)`，建立长度 `n+1` 的滚动数组，全部设为负无穷；`prev[0]=0`。
3. 对 `t=1..r`：
   - 清空 `cur` 为负无穷；
   - 只枚举可达位置 `i`，至少满足 `t≤i≤min(n,3t)`；
   - 从三个合法前驱的最大值转移，并加 `value[i]`；
   - 交换 `prev,cur`。
4. 输出 `prev[n]`。

### 边界与实现注意

- 位置 0 是第一块地砖之前，不含宝物。
- 不可达状态必须用负无穷，不能用 0，因为合法路线收益也可能为 0。
- `m≥n` 时 `r=n`，最优就是每次前进 1 格并拿到所有宝物。
- 还可利用“剩余 `r-t` 步能否到达 `n`”进一步缩小每层位置范围，但不是正确性所必需。
- 当前价值上限约 `5n`，整数足够。

### 复杂度与约束对应

令 `r=min(m,n)`：

- 时间复杂度：`O(nr)`。
- 空间复杂度：`O(n)`。
- 最大状态数为 `10^4×5×10^3=5×10^7`，每个状态只有 3 个前驱；滚动数组避免了同规模二维内存。
