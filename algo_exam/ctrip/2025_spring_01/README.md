# 2025 春招算法岗第一批：算法思路

本文按“观察—推导—正确性—例子—实现”的顺序整理本批算法题，不包含完整代码或输入输出模板。

## q01｜[诗](https://www.nowcoder.com/questionTerminal/7eef94e6f96f401b9078213cbc6c7eaf)

### 题意转化与关键观察

第 1 行写 1 个字符，第 2 行写 2 个字符，依次类推。题目只要每行首字符，因此不必真的构造多行文本，只需计算各行在原字符串中的起始下标。

### 下标推导

采用 1 基行号 `r`。第 `r` 行之前共写了：

`1+2+...+(r-1)=r(r-1)/2`

个字符，所以第 `r` 行首字符的 0 基下标为 `r(r-1)/2`。也可以避免乘法，维护 `pos`：

- 初始 `pos=0,rowLen=1`；
- 取出 `s[pos]` 后，下一行起点是 `pos+rowLen`；
- 再令 `rowLen++`。

只要 `pos<|s|`，这一行至少还有首字符，就应加入答案。

### 正确性说明

每次更新 `pos+=rowLen`，恰好跳过当前行计划书写的字符数。若当前行是最后一行且剩余字符不足 `rowLen`，它的首字符仍位于当前 `pos`，会先被记录；更新后 `pos` 越界，循环自然结束。因此完整行和最后一个不完整行都不会遗漏。

### 示例演算

`s=abcdefghi`，分行为：

- `a`
- `bc`
- `def`
- `ghi`（最后一行只剩 3 个字符，仍照常停止）

行首下标为 `0,1,3,6`，拼接得到 `abdg`。

### 算法步骤

1. 初始化空答案、`pos=0`、`rowLen=1`。
2. 当 `pos<len(s)` 时，把 `s[pos]` 追加到答案。
3. 执行 `pos+=rowLen`，再执行 `rowLen++`。
4. 循环结束后返回答案。

### 边界与实现注意

- 长度为 1 时只输出原字符。
- 最后一行不要求凑满；停止条件是“已经没有首字符”，不是“剩余长度不足当前行长”。
- `|s|≤10^5`，普通整数足够；使用 64 位下标也可避免扩展约束下的三角数溢出。
- 输出字符数约为满足 `r(r-1)/2<|s|` 的行数，即 `O(√|s|)`。

### 复杂度

循环次数和答案长度均为 `O(√|s|)`，时间复杂度 `O(√|s|)`；除返回的答案外额外空间 `O(1)`，计入答案则为 `O(√|s|)`。

## q02｜[游游的数组染色](https://www.nowcoder.com/questionTerminal/d0733785b73f4430aa735d15452b72ab)

### 题意转化与关键观察

选择一个非空集合 `S`，得分为 `min(S)+|S|`。假设已经确定黑色集合的最小值是 `v`，那么任何值不小于 `v` 的未选元素都可以免费加入：最小值不变，黑色个数增加 1，得分一定更高。因此某个最优解必然是一个“按值取上界”的集合。

### 从阈值到排序公式

把数组降序排列为 `b_1≥b_2≥...≥b_n`。若选择前 `i` 个元素，则最小值是 `b_i`，得分为：

`score_i=b_i+i`。

枚举所有 `i` 并取最大值即可。若存在重复值，例如 `b_i=b_{i+1}`，只取前 `i` 个并不是该阈值的最终最优集合，但枚举到这个值的最后一次出现时，会把所有等于它的元素都包括进来，因此不会漏掉最优答案。

### 正确性说明

任取一个最优黑色集合，令其最小值为 `v`。将所有未选且值 `≥v` 的元素加入后，得到的仍是合法集合，且得分不减；这个扩充后的集合恰好对应降序数组的某个前缀。反过来，每个降序前缀都是可选集合。因此只在所有前缀中取最大值与在所有子集中取最大值等价。

### 示例演算

数组 `[5,3,3,1]` 排序后不变，各前缀得分为：

- `5+1=6`；
- `3+2=5`；
- `3+3=6`；
- `1+4=5`。

最大得分为 6。这个例子也说明重复值应看它最后一次出现的前缀。

### 算法步骤

1. 将每组数组按非升序排序。
2. 初始化答案为很小值。
3. 对 0 基下标 `i=0..n-1`，计算 `b[i]+(i+1)`。
4. 用该值更新答案并输出。

### 边界与实现注意

- 必须至少染黑一个元素，不能把空集作为得分 0 的候选。
- `n=1` 时答案为 `a_1+1`。
- 多测试总长度不超过 `3·10^5`，应逐组排序并复用内存。
- 虽然当前约束下答案接近 `10^9`，建议用 64 位整数承接元素值和个数之和。

### 复杂度

每组排序耗时 `O(n log n)`，扫描耗时 `O(n)`；除排序存储外额外空间 `O(1)`。总长度受限，整体可通过 1 秒级约束。

## q03｜[游游的数组询问](https://www.nowcoder.com/questionTerminal/b596c228c8404cdcbcbf2140a727fc89)

### 题意转化与关键观察

令 `ω(x)` 表示 `x` 的不同质因子个数。把原数组映射为权值数组 `w_i=ω(a_i)`。删除长度固定为 `k` 的窗口后：

`剩余权值和 = total - 被删窗口权值和`。

`total` 对所有方案相同，因此最大化剩余和，等价于寻找权值和最小的长度 `k` 窗口。

### 权值预处理与窗口推导

值域只有 `10^4`，可以用类似筛法一次求出所有 `ω(x)`：

1. `ω` 初始为 0。
2. 从 2 枚举到 `A=max(a_i)`；若 `ω[p]=0`，说明 `p` 还未被更小质数更新，因此 `p` 是质数。
3. 遍历 `p,2p,3p,...`，给每个倍数的 `ω` 加 1。

每个质数只给其倍数贡献一次，所以重复质因子不会重复计算，例如 `ω(4)=1`。

得到 `w` 后，先计算前 `k` 项窗口和；窗口每右移一格，加入新权值并减去离开的权值，维护最小窗口和。

### 正确性说明

筛法对每个整数 `x`，恰好在其每个不同质因子 `p` 的倍数遍历中加一次，因此得到的就是不同质因子数量。对于删除部分，由于 `total` 固定，若窗口 A 的权值和小于窗口 B，则删除 A 后保留的权值和必然更大；所以选最小窗口和是充要的。

### 示例演算

`a=[6,4,1,30],k=2`。不同质因子数量为 `w=[2,1,0,3]`，`total=6`。三个长度 2 的窗口和依次为 `3,1,3`，最小值是 1，因此删除中间 `[4,1]`，答案为 `6-1=5`。

### 算法步骤

1. 取数组最大值 `A`，筛出 `0..A` 的 `ω`。
2. 扫描数组，把 `ω(a_i)` 累加进 `total`。
3. 计算第一个长度 `k` 的窗口和并初始化 `minWindow`。
4. 从第 `k+1` 个元素开始滑动：加右端、减左端、更新最小值。
5. 输出 `total-minWindow`。

### 边界与实现注意

- `1` 没有质因子，`ω(1)=0`。
- 题目说“质因子个数”按不同质因子理解；`4=2^2` 的权值仍是 1。
- `k=n` 时唯一窗口就是全数组，答案自然为 0。
- 权值最大很小，但总和仍建议用普通整型或 64 位统一处理。

### 复杂度

设值域上界为 `A≤10^4`。筛法时间 `O(A log log A)`、映射和滑窗时间 `O(n)`，空间 `O(A)`。在 `n≤10^5` 下无需为窗口另开数组。

## q04｜[偶数路径2.0](https://www.nowcoder.com/questionTerminal/c9cb61d300494629b65daa145f23d92e)

### 题意转化与关键观察

一组整数的最大公约数是偶数，当且仅当所有整数都为偶数：

- 若全部为偶数，公约数至少含因子 2；
- 只要路径上出现一个奇数，所有数就不可能拥有公共因子 2，GCD 必为奇数。

所以合法路径正是“路径上的每个节点权值都为偶数”的路径。

### 从树路径到连通分量

删除所有奇数权节点及其相邻边，原树变成若干只含偶数节点的连通分量，每个分量仍是一棵树。设某分量有 `s` 个节点：

- 树中任意两个不同节点之间有唯一简单路径，且该路径完全留在分量内；
- 每个单节点路径也合法。

因此该分量贡献：

`C(s,2)+s=s(s+1)/2`。

把所有偶数分量的贡献相加即可。

### 正确性说明

若一条路径 GCD 为偶数，它不含奇数点，所以所有节点都位于同一个偶数诱导分量，会由其两个端点唯一计数。若两个端点位于同一偶数分量，原树中的唯一路径也完全由偶数点组成，必然合法。不同分量没有共同端点对，而公式按无序端点对计数，因此 `u→v` 与 `v→u` 不会重复。

### 示例演算

链 `1-2-3-4` 的点权为 `[2,4,3,6]`。删除奇数点 3 后，偶数分量大小分别为 2 和 1，贡献为 `2·3/2+1·2/2=4`。对应合法路径是三个偶数单点路径，以及节点 1 到 2 的路径。

### 算法步骤

1. 建立树的邻接表，并标记每个节点权值是否为偶数。
2. 遍历所有节点；遇到尚未访问的偶数节点，启动 DFS/BFS。
3. 搜索时只沿“另一端也是偶数”的边扩展，统计分量大小 `s`。
4. 把 `s(s+1)/2` 加入 64 位答案。
5. 奇数节点直接跳过。

### 边界与实现注意

- `u=u` 的单点路径题目明确计数，所以公式必须包含 `+s`。
- 所求路径无方向，不能使用 `s^2` 之类有序点对公式。
- `n=2·10^5` 时递归 DFS 可能爆栈，优先用显式栈、队列或并查集。
- 最大答案为 `n(n+1)/2`，约 `2·10^10`，必须使用 64 位整数。

### 复杂度

每个节点和每条边至多访问常数次，时间复杂度 `O(n)`；邻接表、访问数组和搜索栈共占 `O(n)`，满足 `n≤2·10^5`。
