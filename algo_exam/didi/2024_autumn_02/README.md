## q01：对比之美

题目链接：[对比之美](https://www.nowcoder.com/questionTerminal/0fcbb83370124426bfee75aca43b7ee7)

### 题意转化与关键观察

需要选择非负整数 `a_1..a_n`，满足总和为 `m`，最大化 `F=sum(|a_i-a_{i-1}|)`。由于 `n,m` 可达 `10^9`，应从不等式上界和可达到该上界的构造入手，而不是枚举分配。

### 从定义到公式的推导

对每条相邻边有 `|a_i-a_{i-1}|<=a_i+a_{i-1}`，求和得到

\[
F\le a_1+a_n+2\sum_{i=2}^{n-1}a_i\le 2m。
\]

内部格子的数量会在左右两条边各出现一次，所以能产生两倍贡献；端点只产生一倍贡献。于是：

- `n=1` 时没有边，答案为 `0`；
- `n=2` 时只有一条边，上界收紧为 `m`，把全部物品放一端可达到；
- `n>=3` 时把全部 `m` 放在一个内部格，左右差均为 `m`，达到总上界 `2m`。

### 正确性说明

不等式给出了所有方案都不能超过的值，集中放置的构造又分别达到对应上界。因此 `0、m、2m` 的分类不仅可行，而且必然最优。

### 示例演算

- `n=5,m=4`：`[0,0,4,0,0]` 的相邻差和为 `0+4+4+0=8`。
- `n=2,m=4`：`[4,0]` 只能得到 `4`，因为只有一条相邻边。
- `n=1,m=4`：答案是空和 `0`。

### 算法步骤

1. 若 `n==1`，令 `ans=0`。
2. 否则若 `n==2`，令 `ans=m`。
3. 否则令 `ans=2*m`。
4. 输出该组答案。

### 实现注意

- 无需保存或输出具体摆法。
- 所有输入和答案用 64 位整数；让常量 `2` 也参与 64 位乘法。
- 多测试用例之间没有状态依赖。
- 最终结论只依赖 `n` 属于哪一种分类，不受 `m` 的具体分配方式影响。

### 复杂度

- 时间复杂度：每组 `O(1)`。
- 空间复杂度：`O(1)`。

## q02：字符消除

题目链接：[字符消除](https://www.nowcoder.com/questionTerminal/c2d5576d39bf41e99bbe2f5ac9270889)

### 题意转化与关键观察

相邻删除会不断改变邻接关系。若把原串中最终一起删除的两个位置连线，配对只能互不相交或彼此嵌套，不可能形成 `l<p<r<q` 的交叉：要让 `l,r` 相邻需先删 `p`，而 `p` 又必须等 `q`，两者矛盾。因此问题等价于在原位置上选择最大权的非交叉完美匹配。

### 从定义到 DP 状态的推导

定义 `dp[l][r]` 为偶数长度区间 `[l,r]` 被完全删除的最大费用，空区间为 `0`。枚举最左位置 `l` 的配对点 `p`：

- `[l+1,p-1]` 必须先删空，故其长度为偶数，`p=l+1,l+3,...`；
- 随后删除已经相邻的 `s[l],s[p]`，得到 `cost(s[l],s[p])`；
- `[p+1,r]` 再独立取最优。

于是

\[
dp[l][r]=\max_p\{dp[l+1][p-1]+cost(s_l,s_p)+dp[p+1][r]\}。
\]

按偶数区间长度递增填表，最后读取整个区间。

### 正确性说明

任意合法方案都能按最左位置的配对点唯一拆成“中间方案 + 当前一对 + 右侧方案”，所以一定出现在转移候选中；而每个候选都能先删中间、再删当前一对、最后删右侧，确实可执行。对子区间使用最优值并取所有 `p` 的最大值，依据区间长度归纳即可证明 `dp` 等于全局最优。

### 示例演算：配对结构

对四个位置 `a b c d`：

- 若 `a` 与 `b` 配对，剩下 `c,d` 配对，总值为 `cost(a,b)+cost(c,d)`；
- 若 `a` 与 `d` 配对，必须先删 `b,c`，总值为 `cost(b,c)+cost(a,d)`。

两种结构都合法；`a` 与 `c` 配对则会留下无法单独消除的 `b`，不合法。

### 算法步骤

1. 用 64 位二维数组保存 `dp`，合法状态以负无穷初始化，空区间按 `0` 处理。
2. `len` 从 `2` 到 `n` 每次增加 `2`。
3. 对每个 `l` 计算 `r=l+len-1`。
4. 对 `p=l+1` 到 `r` 每次增加 `2`，取两个子区间值并加 `cost(s[l],s[p])`。
5. 用候选值更新 `dp[l][r]`。
6. 输出 `dp[0][n-1]`。

### 实现注意

- `cost(a,b)` 不一定等于 `cost(b,a)`，方向必须按原串左、右字符读取。
- `p=l+1` 或 `p=r` 会出现空子区间，应返回 `0`，不要访问越界。
- 若费用可为负，不能把未计算状态默认为 `0`。
- `n<=500`，费用和使用 64 位整数；负无穷应留出加法安全余量。

### 复杂度

- 时间复杂度：`O(n^3)`，在 `n<=500` 下可行。
- 空间复杂度：`O(n^2)`。
