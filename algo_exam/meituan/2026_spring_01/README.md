## q01 小美的因子数量

[题目链接](https://www.nowcoder.com/questionTerminal/d1b4e55bfc914700a6545a79282e8591)

### 1. 关键数学性质

若 d 是正整数 x 的因子，那么 x/d 也是因子。通常它们成对出现：

    d × (x/d) = x

只有当 d=x/d，也就是 d²=x 时，这一对才会重合。因此：

- x 不是完全平方数：所有因子两两配对，因子数为偶数；
- x 是完全平方数：平方根只出现一次，因子数为奇数。

题目要求的数恰好就是区间中的完全平方数。

### 2. 区间计数公式

不超过 y 的正完全平方数为：

    1², 2², ..., floor(sqrt(y))²

数量是 floor(sqrt(y))。因此 [l,r] 中的数量为：

    floor(sqrt(r)) - floor(sqrt(l-1))

### 3. 正确性说明

因子配对证明了“因子数为奇数”和“完全平方数”互为充要条件。前缀函数 floor(sqrt(y)) 精确统计 [1,y] 内的平方数，用右端前缀减去 l-1 的前缀，正好留下 [l,r]，没有边界重叠。

### 4. 示例演算

区间 [5,30] 中的完全平方数是：

    9, 16, 25

公式给出：

    floor(sqrt(30)) - floor(sqrt(4))
    = 5 - 2
    = 3

### 5. 算法步骤

1. 求 r 的整数平方根 R。
2. 求 l-1 的整数平方根 L。
3. 输出 R-L。

### 6. 边界与实现注意

- l=1 时 l-1=0，整数平方根为 0。
- r≤10^9，float64 初值通常足够，但稳妥做法是取浮点平方根后用整数乘法向上或向下校正，避免恰在平方数边界时偏一。
- 校正比较使用 64 位整数计算 x×x。

具体地，对 y 先取得候选整数 x，再检查 `(x+1)²≤y` 时令 x 增加，检查 `x²>y` 时令 x 减少，直至同时满足 `x²≤y<(x+1)²`。这个不等式唯一确定 `floor(sqrt(y))`，因此即使浮点初值落在边界相邻整数上，校正后的结果也不会偏一。y=0 时直接得到 0，校正过程同样成立。

### 7. 复杂度

- 使用内置平方根并常数次校正：时间 O(1)，空间 O(1)。
- 若完全使用二分整数平方根：时间 O(log r)，空间 O(1)。

## q02 超级斐波那契数列

[题目链接](https://www.nowcoder.com/questionTerminal/744105b169f645ecb9383ae2b0e43e69)

### 1. 直接递推的问题

序列定义为：

    S_i = 1                              当 i≤k
    S_i = S_(i-1)+...+S_(i-k)            当 i>k

如果每求一项都重新累加前 k 项，预处理到 10^6 需要 O(k×maxX)，最坏无法通过。相邻两项使用的求和窗口只差一个进入项和一个离开项，可以维护滑动和。

### 2. 滑动窗口推导

在计算 S_i 前，维护不变量：

    window = S_(i-k)+S_(i-k+1)+...+S_(i-1)

于是：

    S_i = window

下一项需要的窗口是 S_(i-k+1)…S_i，因此更新：

    window = window + S_i - S_(i-k)

每一步都是 O(1)。

### 3. 示例演算

k=3 时：

    S1=S2=S3=1
    window=1+1+1=3
    S4=3

更新窗口：

    window=3+S4-S1=3+3-1=5
    S5=5

继续更新：

    window=5+S5-S2=5+5-1=9
    S6=9

序列前六项为 1,1,1,3,5,9。

### 4. 为什么预处理一次即可

所有查询共享同一个 k 和同一条序列。先取得最大查询位置 maxX，计算 S_1…S_maxX 后，每次查询只需数组下标访问。滑动窗口不变量保证每个新值严格等于定义中的前 k 项之和，因此预处理结果与原递推完全一致。

### 5. 算法步骤

1. 读入并保存 q 个查询，求 maxX。
2. 若 maxX≤k，所有答案都是 1，可直接回答。
3. 初始化 S_1…S_k=1，并令 window=k mod MOD。
4. 从 i=k+1 到 maxX：
   - S_i=window；
   - window=(window+S_i-S_(i-k)) mod MOD。
5. 按原查询顺序输出 S_x。

### 6. 边界与实现注意

- 初始化只应写到 min(k,maxX)，否则 maxX<k 时会越界。
- 做减法后可能得到负余数，需要加 MOD 再取模。
- k=1 时序列恒为 1，滑动窗口公式同样成立。
- 可以固定预处理到 10^6 并流式回答；若只算到 maxX，则需要先保存查询。

### 7. 复杂度

- 时间复杂度：O(maxX+q)，maxX≤10^6。
- 空间复杂度：O(maxX+q)；固定预处理上限并直接回答时，可省去查询数组的 O(q)。

## q03 最大节点权值

[题目链接](https://www.nowcoder.com/questionTerminal/7972973f321345389006f32fdfe4fea3)

### 1. 为什么要倒序

正序操作会删除边，连通块可能分裂，并且删除边的两个端点度数减一。动态维护“删除后的连通块最大权值”很困难。

把全部操作倒序：

- 删除边变成添加边；
- 连通块只会合并，不会分裂；
- 两个端点的度数只会增加；
- 节点权值 id+degree 也只会增加。

这正好适合并查集。

### 2. 构造倒序起点

先标记正序中会被删除的所有边。执行完全部操作后的图只包含从未删除的边：

1. 用这些边计算每个节点的最终度数 degree[v]；
2. 用并查集合并这些边；
3. 每个连通块根维护：

       componentMax[root]
       = max(v + degree[v])，v 属于该块

这就是倒序处理开始时的准确图状态。

### 3. 倒序恢复一条边

恢复边 (u,v) 时，无论两个端点是否已经连通，它都使：

    degree[u] += 1
    degree[v] += 1

所以先用新的 u+degree[u]、v+degree[v] 更新各自当前连通块的 componentMax。然后：

- 若根不同，合并两个块，新根最大值取两个旧最大值的较大者；
- 若根相同，不需要合并，但两次端点权值更新仍然必须执行。

倒序遇到原来的查询时，当前并查集状态恰好对应那个正序时刻，直接输出 componentMax[find(x)]。

### 4. 正确性不变量

在倒序处理任意一个操作之前，维护：

1. 并查集划分与该正序时刻的图连通块完全相同；
2. degree[v] 等于该时刻节点 v 的当前度；
3. componentMax 保存块内所有 v+degree[v] 的最大值。

初始最终图满足不变量。倒序查询不改变状态；倒序加边只增加两个端点度并合并对应连通块，按上述更新后仍满足不变量。归纳可知每次查询答案都正确。

### 5. 示例演算

有节点 1、2、3，边 e1=(1,2)、e2=(2,3)，正序删除 e2。

删除完成后的图：

    连通块 {1,2}，度数 [1,1]
    连通块 {3}，度数 [0]

权值分别为 2、3、3，所以 {1,2} 的 componentMax=3，{3} 也为 3。

倒序恢复 e2 时，degree[2] 从 1 变 2、degree[3] 从 0 变 1，权值变为 4、4；再合并两个块，新 componentMax=4。这正是删除 e2 之前整张图的状态。

### 6. 算法步骤

1. 读入全部操作，标记被删除边。
2. 用未删除边建立最终图：计算度数、并查集合并。
3. 初始化每个连通块的 componentMax。
4. 从后向前扫描操作：
   - 查询：记录 componentMax[find(x)]；
   - 删边：按“端点度数加一、更新块最大值、合并”的顺序恢复。
5. 将记录的查询答案反转后输出。

### 7. 边界与实现注意

- m 可以为 0，并查集仍需为每个单点初始化权值 v。
- 一条被恢复的边可能连接同一连通块，不能因此漏掉端点度数变化。
- 先更新端点所在旧块，再 union 最直观；union 时必须合并 componentMax。
- 操作与边的数量可达 2×10^5，应保存全部操作并使用缓冲输入。
- 最大权值至多 n+m 量级，普通 64 位整数足够。

### 8. 复杂度

每条边和每次操作只触发常数次并查集操作：

- 时间复杂度：O((n+m+q) α(n))。
- 空间复杂度：O(n+m+q)。
