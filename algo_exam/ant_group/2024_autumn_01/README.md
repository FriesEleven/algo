# 2024 秋招算法岗：算法思路

本文按“观察—推导—正确性—例子—实现”的顺序整理本批算法题，不包含完整代码或输入输出模板。

## q01｜[小苯的格子移动](https://www.nowcoder.com/questionTerminal/d1c43a534cb943398e6fafcc5e27aefb)

### 题意转化与关键观察

移动方向只有从 `i` 到 `i+1`，不存在绕路或回退选择。对于同一个格子，到达得越早，后续选择只会更多，不会更差；若下一格尚未解锁，提前到达后等待与在前一格等待效果相同。因此只需维护“到达当前格的最早时刻”。

### 递推公式

令 `time_i` 表示最早到达第 `i` 格的时刻。初始已经位于第 1 格，所以 `time_1=0`。

从第 `i-1` 格移动一步至少花 1 秒，同时第 `i` 格必须在时刻 `a_i` 后才能进入，因此：

`time_i=max(time_{i-1}+1,a_i)`。

两项分别代表“移动时间约束”和“解锁时间约束”，取较大值就是同时满足二者的最早时刻。

### 正确性说明

用归纳法说明。假设 `time_{i-1}` 已是到达第 `i-1` 格的最早时刻，那么任何方案到达第 `i` 格都不可能早于 `time_{i-1}+1`，也不可能早于 `a_i`，所以递推值是下界。实际方案可以在第 `i-1` 格等到 `max(time_{i-1},a_i-1)`，下一秒进入第 `i` 格，恰好达到该下界，故它就是最优值。

### 示例演算

`a=[0,3,1,6]`：

- 初始 `time=0`；
- 第 2 格：`max(1,3)=3`；
- 第 3 格已经解锁：`max(4,1)=4`；
- 第 4 格：`max(5,6)=6`。

最早 6 秒到达终点。

### 算法步骤

1. 令 `time=0`，第一个解锁时间只需读入。
2. 从 `i=2` 扫描到 `n`。
3. 每次更新 `time=max(time+1,a_i)`。
4. 扫描结束后输出 `time`。

### 边界与实现注意

- `n=1` 时不移动，答案为 0。
- “第 `a_i` 秒之后（包括该秒）”意味着到达时刻恰好等于 `a_i` 合法。
- 解锁时间不要求单调，递推不依赖这个性质。
- 当前约束下 `time≤10^9+n`，但建议使用 64 位整数处理时间。
- 所有测试的 `n` 总和受限，可边读边算，无需保存数组。

### 复杂度

每组扫描 `n-1` 个格子，时间复杂度 `O(n)`、额外空间 `O(1)`；总时间为 `O(Σn)`，其中 `Σn≤2·10^5`。

## q02｜[信用评分模型优化](https://www.nowcoder.com/questionTerminal/aec5f31464954a4d986f541b6f71eeef)

### 题意转化与关键观察

题目要求的不是手工设计一个新的特征评分，而是按给定数据训练决策树，再返回树模型给出的最重要特征下标。最后一列是目标标签，倒数第二列是类别字符串特征，其余为数值特征；因此关键是正确拆分、编码并保证训练过程可复现。

### 特征重要度从哪里来

决策树在节点 `t` 使用特征 `j` 分裂时，会减少加权不纯度。以默认 Gini 指标为例，该节点对特征 `j` 的贡献可写为：

`Δ_t=(N_t/N)·[I(t)-(N_L/N_t)I(L)-(N_R/N_t)I(R)]`。

把所有使用特征 `j` 的节点贡献相加，再对全部特征归一化，就得到 `feature_importances_[j]`。所以实现时应直接取训练后重要度数组的最大值下标，而不是用相关系数或单次分裂结果替代。

### 数据处理与模型步骤

1. 令 `X` 为除最后一列外的所有列，`y` 为最后一列。
2. 把倒数第二列类别特征做确定性整数编码；同一字符串始终映射到同一整数。
3. 把 `Good/Bad` 编成两个分类标签。
4. 使用全部记录拟合 `DecisionTreeClassifier(random_state=42)`。
5. 读取 `feature_importances_`，返回最大元素的 0 基下标。

### 正确性说明

类别编码只把离散名称替换为模型可接收的数值表示，不改变同类样本的一致性。决策树训练完成后，库按照整棵树各分裂造成的不纯度下降累计特征贡献，这正是题目指定的“基于决策树的特征选择”。固定 `random_state=42` 后，同分候选的内部选择也可复现；题目保证最终最重要特征唯一，取 `argmax` 不会产生歧义。

### 示例演算

假设 4 条记录的特征 0 为 `[0,0,1,1]`，标签为 `[Bad,Bad,Good,Good]`，另一个特征恒为 7。用特征 0 一次就能把两类完全分开，根节点不纯度从正值降为 0；常量特征无法分裂，贡献为 0。因此重要度最大下标是 0。

### 算法步骤

1. 检查二维数据至少包含一个特征列和一个标签列。
2. 拷贝特征矩阵，单独编码其中的字符串特征列；构造标签向量。
3. 创建带固定随机种子的分类决策树并调用拟合。
4. 遍历重要度数组，记录最大值及其最小下标。
5. 返回原始特征下标；不要把标签列计入编号。

### 边界与实现注意

- 必须固定随机种子 42，否则相同增益候选可能因内部顺序得到不同树。
- 类别编码映射应在整列上统一建立，不能逐行重置。
- 无需拆分训练集和测试集：题目要的是给定数据上的特征选择，不是泛化评估。
- 不要对特征做字符串排序后改变列顺序；输出下标对应原输入特征列。
- 若自行实现编码，需保证数值列仍保持数值类型。

### 复杂度

设样本数为 `R`、特征数为 `F`。预处理时间和存储均为 `O(RF)`。常见平衡树训练约为 `O(FR log R)`，最坏退化树可能达到 `O(FR^2)`；模型和工作数组通常占 `O(RF)` 量级。实际复杂度由所用决策树库实现决定。

## q03｜[小红的区间选数乘积](https://www.nowcoder.com/questionTerminal/cf2d0123e80e4eb68a8f769db214fe62)

### 题意转化与关键观察

把 `x` 的质因数分解写成 `x=∏p^{e_p}`。乘积 `xy` 是完全平方数，当且仅当每个质因子的总指数都是偶数。于是 `y` 对每个质因子的指数奇偶性已经被 `x` 唯一决定。

### 从指数奇偶到计数公式

取出 `x` 中指数为奇数的质因子并相乘：

`s=∏_{e_p为奇数}p`。

`s` 是 `x` 的平方自由核，且可写成 `x=s·t^2`。要让 `xy` 成为平方数，`y` 必须且只需形如：

`y=s·z^2，z≥1`。

因为 `s` 把所有奇指数各补一次，而 `z^2` 只增加偶数指数。

不超过 `R` 的合法 `y` 数量是：

`F(R)=floor(sqrt(floor(R/s)))`。

所以区间 `[l,r]` 的答案为 `F(r)-F(l-1)`。

### 正确性说明

若 `y=s·z^2`，则 `xy=(st^2)(sz^2)=(stz)^2`，一定为平方数。反过来，若 `xy` 为平方数，则 `y` 的每个质因子指数与 `x` 同奇偶；除去核 `s` 后所有指数均为偶数，剩余部分必然是某个 `z^2`。因此公式既不漏也不多。

### 示例演算

`x=12=2^2·3`，平方自由核 `s=3`。取 `[l,r]=[1,30]`，合法数是 `3·1^2=3`、`3·2^2=12`、`3·3^2=27`，共 3 个。公式给出 `isqrt(30/3)-isqrt(0)=3`。

### 算法步骤：大整数分解与计数

1. 用确定性 Miller–Rabin 对 `x` 做 64 位范围素性测试。
2. 对合数使用 Pollard–Rho 找到一个非平凡因子，再递归分解两侧。
3. 排序或哈希统计每个质因子的出现次数，只把奇数次的质因子乘入 `s`。
4. 实现精确整数平方根 `isqrt(v)`。
5. 计算 `isqrt(r/s)-isqrt((l-1)/s)`。
6. 若多个询问可能出现相同的 `x`，可缓存 `x→s`，避免重复执行 Pollard–Rho 分解。

伪代码关系为：

`f(R)=isqrt(R/s)`，`answer=f(r)-f(l-1)`。

### 边界与实现注意

- `x=1` 时没有质因子，空乘积 `s=1`，合法 `y` 就是完全平方数。
- `l=1` 时 `l-1=0`，`isqrt(0)=0`。
- 浮点 `sqrt` 在 `10^14` 附近可能舍入错误；即便用浮点作初值，也要用整数乘法向上、向下校正。
- Pollard–Rho 的模乘必须避免 64 位溢出，可用 128 位中间类型或安全加法乘法。
- Miller–Rabin 要使用覆盖目标整数范围的确定性底数集合；随机过程可固定或可靠播种。
- `q` 可达 `10^4`，除缓存重复 `x` 外，素数输入应先由 Miller–Rabin 快速结束，不能统一试除到 `sqrt(x)`。

### 复杂度

区间计数本身为 `O(1)`。瓶颈是分解 `x`：Pollard–Rho 为随机期望复杂度，常用估计约 `O(x^{1/4})`，实际对 `x≤10^14` 通常很快；缓存后只需分解不同的 `x`。递归栈和因子表空间为 `O(log x)` 量级，缓存额外占 `O(u)`，其中 `u` 为不同 `x` 的数量。
