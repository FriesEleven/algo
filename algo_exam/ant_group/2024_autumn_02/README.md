# 2024 秋招工程研发岗第二批：算法思路

本文按“观察—推导—正确性—例子—实现”的顺序整理本批算法题，不包含完整代码或输入输出模板。

## q01｜[小红的括号串](https://www.nowcoder.com/questionTerminal/7101833a87444483919eb938f19cfea9)

### 题意转化与关键观察

合法括号串可用余额描述：读到 `(` 时余额加 1，读到 `)` 时余额减 1；所有前缀余额必须非负，最终余额必须为 0。四种长度为 2 的块具有如下性质：

| 块 | 净余额 | 从非负余额开始时的要求 |
|---|---:|---|
| `((` | `+2` | 总是安全 |
| `))` | `-2` | 开始余额至少为 2 |
| `()` | `0` | 总是安全 |
| `)(` | `0` | 开始余额至少为 1 |

### 充要条件推导

总余额只由 `((` 和 `))` 决定，等于 `2a-2b`，所以必须有 `a=b`。

再看 `)(`：

- 若 `d=0`，只要 `a=b`，把所有 `((` 放前面、`))` 放后面，`()` 任意放置即可。
- 若 `d>0`，第一个 `)(` 以右括号开头，放置前必须已有正余额。只有 `((` 能产生正净余额，因此还必须 `a>0`。

故完整条件是：

`a=b 且 (d=0 或 a>0)`。

### 正确性说明

当条件成立时，可构造顺序：

1. 先放全部 `((`，余额升到 `2a`；
2. 再放全部 `)(`，每个块内部只暂时下降 1，随后恢复，`a>0` 时不会为负；
3. `()` 放在任意非负余额处都安全；
4. 最后放全部 `))`，余额每次下降 2，因 `a=b` 恰好降到 0。

必要性已由最终余额和 `)(` 的首字符说明，因此该判断是充要的。

### 小例子

`a=b=1,c=0,d=2` 时，可排列为 `(( + )( + )( + ))`。余额变化为 `1,2,1,2,1,2,1,0`，始终非负，合法。

`a=b=0,d=1` 时只有 `)(`，第一个字符就让余额变为 `-1`，无论如何都不合法。

### 算法步骤

1. 对每组读取 `a,b,c,d`。
2. 若 `a!=b`，输出 `NO`。
3. 否则若 `d>0` 且 `a=0`，输出 `NO`。
4. 其余情况输出 `YES`。

### 边界与实现注意

- `a=b=c=d=0` 对应空串，按题意示例属于合法括号序列。
- 只有若干 `()` 时始终合法。
- `c` 不影响可行性，因为 `()` 净余额为 0 且自身前缀安全。
- 数量可达 `10^9`，但只比较相等和是否为 0，不需要构造实际字符串。

### 复杂度

每组只做常数次比较，时间复杂度 `O(1)`、额外空间 `O(1)`。`T≤10^5` 时总时间 `O(T)`。

## q02｜[小苯的最小好数](https://www.nowcoder.com/questionTerminal/9ae46830704e4d2399f025074ffcb949)

### 题意转化与关键观察

同长度的十进制正整数按数值排序，等价于按数字串字典序排序。因此目标是构造“不小于 `x` 的、数位互异的字典序最小字符串”。若 `x` 本身数位互异，答案就是 `x`；否则应尽量保留最长的相同前缀，只在不得不改变的位置增大一个数字，再把后缀填到最小。

### 从第一个重复位向前回退

设 `digits` 是 `x` 的十进制串，`bad` 是第一个出现重复数字的位置。`bad` 之前的前缀数位一定互异。

从 `p=bad` 向左尝试：

1. 固定 `digits[0..p-1]`；
2. 在未被前缀使用的数字中，选最小的 `d>digits[p]`；若 `p=0`，还要求 `d≠0`；
3. 一旦找到，把剩余位置用尚未使用的数字从小到大填满。

如果当前位置找不到可增大的数字，就继续向左回退。若所有位置都失败，则任何同长度好数都小于 `x`，答案应取位数加一后的最小好数：首位选 1，后续依次选当前未使用的最小数字。

### 正确性说明

数值比较首先取决于第一个不同位置。扫描 `p` 从右向左，等价于优先保留最长的 `x` 前缀；这比在更靠左位置增大一定更小。固定 `p` 后，选择最小可用的更大数字最优；一旦该位已经严格大于 `x`，后缀不再受下界限制，按升序填入最小剩余数字得到字典序最小后缀。因此每层选择都保持全局最小。

### 状态演算示例

`x=1213`，第一个重复位置是下标 2（数字 1 已出现）。保持前缀 `12` 时，当前位置可用且大于 1 的最小数字是 3；剩余未用数字中最小的是 0，于是得到 `1230`。它数位互异且不小于 1213；任何仍以 `12` 开头的更小合法数都不存在。

再如 `x=987667`，从第一个重复位一路向左都找不到可增大的未用数字，同长度无解，转而构造 7 位最小好数 `1023456`。

### 算法步骤

1. 把 `x` 转成数字数组，扫描并记录每一位之前的已用数字掩码，同时找到第一个重复位置。
2. 若没有重复，直接返回 `x`。
3. 从 `bad` 递减到 0：
   - 由前缀重新得到已用掩码；
   - 尝试 `digits[p]+1..9` 中最小的未用合法数字；
   - 找到后，将剩余位依次填入最小未用数字并返回。
4. 若同长度失败，构造长度 `L+1` 的最小无重复数字串。

也可以使用按数字从小到大搜索的数位回溯；核心仍是状态 `(位置,已用掩码,是否仍贴着下界)`。

### 边界与实现注意

- 数字 0 可以出现在非首位，构造最小后缀时通常应优先使用。
- 首位绝不能为 0。
- `x≤10^9`，答案最多 10 位且一定存在；例如 10 位仍可使用全部十个数字各一次。
- 返回值可能超过 32 位有符号整数，应使用 64 位整数或直接构造字符串。
- 若采用通用回溯，选择了严格大于下界的数字后，后缀应直接贪心填最小，不必继续指数搜索。

### 复杂度

数位长度最多 10。每个回退位置最多检查 10 个数字、填充至多 10 位，时间复杂度可记为 `O(10^2)`，空间 `O(10)`；即使 `T=10^5` 也只是很小的常数工作量。

## q03｜[小红的坐标移动(Hard Version)](https://www.nowcoder.com/questionTerminal/cc713e2689074c11aeb9b1b9758f6962)

### 题意转化与关键观察

处理完某段指令后，可能位置不是单点而是一个集合。普通布尔数组做一次转移要扫描 `n` 个位置，总复杂度 `O(n|s|)`，在两者均为 `10^5` 时不可行。把可达集合压成位集后，一次整体左移或右移就能同时完成一个机器字中的 64 个状态。

### 位集状态与转移

令第 `p-1` 位代表位置 `p`，当前可达位集为 `S`，有效位掩码为 `validMask`。

- 执行 `L`：普通位置向左一格，对应 `S>>1`；原来位置 1 可达时，向左仍停在位置 1，因此还要保留最低位。
- 执行 `R`：对应 `(S<<1)&validMask`；原来位置 `n` 可达时，向右仍停在 `n`，因此保留最高有效位。
- 执行 `?`：它可以是任一方向，所以新集合是 `moveL(S) | moveR(S)`。

多机器字实现时，移位需要把相邻字的最高位或最低位作为进位传递。

### 正确性说明

位集中的每个 1 与一个可达位置一一对应。移位恰好把所有内部位置映射到移动后的坐标；额外保留端点位精确实现了“撞到边界则原地不动”。`?` 的所有可能终点就是 L 结果集合与 R 结果集合的并集。由指令前缀长度归纳，每一步后的位集恰好等于所有可能位置集合。

### 状态演算示例

`n=4,k=2,s=?R`：

1. 初始集合为 `{2}`；
2. `?` 可向左或向右，得到 `{1,3}`；
3. 再执行 `R`：位置 1 到 2，位置 3 到 4，最终集合 `{2,4}`。

因此输出位置 1 到 4 的可达标记为 `0 1 0 1`。

边界例子：若当前位置集合含位置 1，执行 `L` 后最低位必须仍为 1，不能因右移而丢失。

### 算法步骤

1. 分配 `ceil(n/64)` 个无符号 64 位字，初始只置位 `k-1`。
2. 为 `moveL` 实现跨字右移，并在原最低位为 1 时补回位置 1。
3. 为 `moveR` 实现跨字左移，清除最后一个字中超过 `n` 的位，并按需补回位置 `n`。
4. 顺序扫描指令：L 取左移结果，R 取右移结果，`?` 取二者按位或。
5. 扫描 `1..n`，按对应比特输出 0 或 1。

### 边界与实现注意

- `n=1` 时 L、R、`?` 后都只能在位置 1。
- 边界规则是原地不动，不是把越界分支删除。
- 当 `n` 不是 64 的倍数时，每步右移结果都应清掉最后机器字的高位垃圾。
- 计算 `?` 时两个方向必须都从同一个旧状态生成，不能先原地更新 L 再基于它计算 R。
- 使用双缓冲位集可避免频繁分配；输出阶段再逐位检查。

### 复杂度

设机器字宽 `w=64`。每条指令扫描 `ceil(n/w)` 个机器字，时间复杂度 `O(|s|·ceil(n/w))`，空间复杂度 `O(ceil(n/w))`（双缓冲仍是同一量级）。相比 `O(n|s|)`，理论上获得约 64 倍并行压缩，适配 `n,|s|≤10^5`。
