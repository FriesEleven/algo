## q01 选数

[题目链接](https://www.nowcoder.com/questionTerminal/9e938a706419422d9baf0132a7413b4d)

### 1. 题意转化

把整数 1 到 n 是否被选择写成长度为 n 的 01 串，其中 1 表示选中。一个被选中的 i 得分，当且仅当 i+1 没有被选中；对于 i=n，n+1 不在选择范围内，也视为没有被选中。

观察每一段连续的 1：

    001110011
      ^    ^

一段中只有最后一个 1 的后继是 0 或越过右边界，因此每个连续的已选区间恰好贡献 1 分。问题等价为：

> 在长度 n 的 01 串中放置 k 个 1，最多能形成多少段连续的 1？

### 2. 上界推导

设最终形成 r 段：

- 每一段至少含一个 1，所以 r≤k；
- 相邻两段之间至少需要一个 0，共需 r-1 个 0；
- 0 的总数为 n-k，所以 r-1≤n-k，即 r≤n-k+1。

因此：

    r ≤ min(k, n-k+1)

### 3. 为什么上界一定能达到

- 若 k≤n-k+1，说明 0 足够分隔所有 1，可以按 10101… 放置，让每个 1 单独成段，得到 k 段。
- 若 k>n-k+1，把 n-k 个 0 全部用作分隔符，天然得到 n-k+1 个空隙；把 k 个 1 分配到这些非空段中，就能得到 n-k+1 段。

所以上界也是答案：

    answer = min(k, n-k+1)

### 4. 示例演算

n=7、k=3 时，可以选择 {1,3,7}：

    1010001

共有 3 段，答案为 min(3,5)=3。

n=7、k=5 时，只有 2 个未选位置，最多分出 3 段。例如：

    1101011

共有 3 段，答案为 min(5,3)=3。

### 5. 算法步骤

每组数据直接计算：

    min(k, n-k+1)

不需要真正构造选择集合。

### 6. 边界与实现注意

- k=n 时所有数连续成一段，公式给出 1。
- k=1 时只选一个数，公式给出 1。
- n、k 可达 10^12，必须使用 64 位整数读取和计算。
- 测试组数较大，每组必须做到常数时间。

### 7. 复杂度

- 时间复杂度：每组 O(1)，总计 O(T)。
- 空间复杂度：O(1)。

## q02 字符串挪移

[题目链接](https://www.nowcoder.com/questionTerminal/74b2c3a0a10f423ab8a0b956d2629d48)

### 1. 关键观察

第 i 次操作把当前字符串第 i 个字符移到末尾。操作完成后，位置 1 到 i-1 已经不会再被后续操作触碰；而原来位置 i+1 的字符会左移到位置 i，并从此固定。

把还没有固定的字符看成一个循环队列。每轮发生的事情是：

1. 当前队首被移到队尾；
2. 新的队首成为下一位固定字符，从队列中移除并写入答案。

这与“每次数到第 2 个元素就淘汰”的约瑟夫过程完全相同。所有淘汰字符按顺序组成最终字符串的前 n-1 位，最后的幸存字符是第 n 位。

### 2. 正确性不变量

进行完 i 次操作后：

- 答案中已经写入 i 个字符，它们正是当前字符串不可再改变的前缀；
- 队列按当前字符串剩余后缀的顺序保存所有未固定字符；
- 下一次操作仍是“队首移到队尾，再固定新队首”。

初始时答案为空、队列是原下标 1…n，不变量成立；每轮按上述两步更新后仍成立。因此队列过程得到的就是题目 n 次操作后的顺序。

### 3. 示例演算

字符串 abqde，对应下标队列 [1,2,3,4,5]：

    移 1 到队尾，固定 2(b)，剩余 [3,4,5,1]
    移 3 到队尾，固定 4(d)，剩余 [5,1,3]
    移 5 到队尾，固定 1(a)，剩余 [3,5]
    移 3 到队尾，固定 5(e)，剩余 [3]
    最后追加幸存者 3(q)

最终得到 bdaeq，与逐次修改字符串的结果一致。

### 4. 算法步骤：线性队列实现

不需要使用会频繁搬移元素的字符串切片。可以使用容量约 2n 的数组队列和 head、tail：

1. 初始把下标 0…n-1 放入队列。
2. 当队列长度大于 1：
   - 取出队首并追加到队尾，表示“移到字符串末尾”；
   - 再取出新的队首，把对应字符追加到答案。
3. 把最后剩余下标对应的字符追加到答案。

总共只会额外入队 n-1 次，预留 2n 空间即可。

### 5. 边界与实现注意

- n=1 时循环不执行，答案就是原字符。
- 操作使用的是“当前字符串的第 i 位”，不能误解成原字符串下标 i。
- 输入长度可达 10^6，O(n²) 的删除或拼接无法通过。
- Go 中答案应预分配 n 字节，避免反复扩容。

### 6. 复杂度

- 时间复杂度：O(n)，每个字符被固定一次。
- 空间复杂度：O(n)，用于队列和答案。

## q03 交替加减

[题目链接](https://www.nowcoder.com/questionTerminal/27965d31fb724123bfa928c1f5fc2768)

### 1. 为什么不能直接模拟

长度 n 的数组会依次变成 n-1、n-2、…、1。逐层计算需要：

    (n-1)+(n-2)+...+1 = O(n²)

次运算，而 n 可达 10^5，必须直接求出原数组每一项在最终答案中的系数。

### 2. 表示每一层的符号

从第 0 层开始编号。第 r 层当前长度为 n-r，在它之前已经写过的符号数为：

    K_r = r(n-1) - r(r-1)/2

若 K_r 为偶数，本层第一个符号是加号；若为奇数，本层第一个符号是减号。记：

    s_r = (-1)^(K_r)

那么本层的转移为：

    b_i = a_i + s_r × (-1)^(i-1) × a_(i+1)

位置 i 上额外的交替符号导致不同位置看起来无法统一，下一步用一个固定符号变换消掉它。

### 3. 消去位置相关符号

定义：

    d_i = (-1)^((i-1)(i-2)/2)
    c_i = d_i × a_i

d_i 的符号按 +,+,-,- 四项循环，并满足：

    d_(i+1) = (-1)^(i-1) × d_i

代入本层转移后：

    c'_i = c_i + s_r × c_(i+1)

现在一整层只相当于给系数多项式乘上 (1+s_r x)。全部 n-1 层结束后：

    P(x) = ∏(1+s_r x)
         = (1+x)^p × (1-x)^q

其中 p、q 分别是起始符号为加、减的层数。若 P 的 x^j 系数为 coef_j，则最终答案为：

    Σ coef_(i-1) × d_i × a_i

### 4. 如何在线性时间求多项式系数

该符号序列按 4 层周期变化，可以证明 |p-q|≤2。于是：

    P(x)
    = (1-x²)^min(p,q)
      × (1+x)^(p-q)        当 p≥q

或：

    P(x)
    = (1-x²)^min(p,q)
      × (1-x)^(q-p)        当 q>p

第一部分只有偶数次项：

    [x^(2t)] (1-x²)^m = (-1)^t × C(m,t)

剩余因子的次数最多为 2，只需把这个稀疏系数数组与一次或两次 (1±x) 做常数次线性卷积，就能得到 P 的全部系数。

### 5. 正确性说明

变量替换只是给每个位置乘以 ±1，可逆且不会丢失信息。每一层都被严格等价地改写为 c'_i=c_i+s_r c_(i+1)，连续执行各层就是连续乘上对应的一次因子。多项式乘积展开时，x^j 系数恰好汇总了原第 j+1 项到最终位置的所有路径贡献，因此最后的线性组合与逐层操作完全相同。

### 6. 示例演算

n=4 时三层的起始符号依次为 +、-、-：

    P(x) = (1+x)(1-x)²
         = 1 - x - x² + x³

而 d=[1,1,-1,-1]，最终原数组系数为：

    [1,-1,1,-1]

所以答案是：

    a1-a2+a3-a4

样例 [1,2,3,4] 得到 1-2+3-4=-2。

### 7. 算法步骤

1. 依次枚举 n-1 层，通过已写符号数的奇偶性统计 p、q。
2. 令 m=min(p,q)，用组合数计算 (1-x²)^m 的偶数项系数。
3. 根据 p-q 的符号，再乘至多两次 (1+x) 或 (1-x)。
4. 按 +,+,-,- 循环得到 d_i。
5. 累加 coef_(i-1)×d_i×a_i，并对 10^9+7 规范取模。

### 8. 边界与实现注意

- n=1 时没有任何符号，答案就是 a1。
- 组合数中的减号和 d_i 都可能产生负值，每一步取模后要加模数规范化。
- n 小于模数，可预处理阶乘与逆阶乘求组合数；也可用递推计算相邻组合数。
- 乘法应使用 64 位整数，防止两个模内整数相乘溢出 32 位。

### 9. 复杂度

- 统计符号、生成系数和求答案均为 O(n)。
- 若用快速幂求一次逆元，还需 O(log MOD)，不改变总复杂度。
- 时间复杂度：O(n+log MOD)。
- 空间复杂度：O(n)。
