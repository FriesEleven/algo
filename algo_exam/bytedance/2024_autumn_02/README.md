## q01：小红的区间删除

题目链接：[小红的区间删除](https://www.nowcoder.com/questionTerminal/69d1f3e2b1624e958cbf81d74b6cd840)

### 题意转化与关键观察

一次操作选择下标 `l<r` 且 `a_l=a_r`，删除严格位于两端之间的元素，因此删除数量是 `r-l-1`。题目允许“最多一次”，所以若没有能删除正数个元素的选择，答案就是 0。

对同一个数值而言，想让下标距离最大，左端应取它第一次出现的位置，右端应取最后一次出现的位置。无需保存所有出现下标，也无需枚举所有相等位置对。

### 从位置对到在线统计

从左到右扫描下标 `i`，用哈希表 `first[value]` 保存该值第一次出现的位置：

- 第一次遇到 `value` 时记录 `i`；
- 再次遇到时，用 `i-first[value]-1` 更新答案，但不修改首次位置。

最后一次出现自然会在扫描过程中产生该值最大的候选。保留第一次位置而非上一次位置，是获得最远端点的关键。

### 正确性说明

固定一个值 `v`，任意合法端点都是它的两个出现位置。删除数随 `r-l` 增大而增大，所以在所有出现位置中，最早与最晚的组合唯一达到最大距离。算法始终保存最早位置，并对包括最晚位置在内的每次出现进行比较，因而会得到该值的最优删除数。再对所有值取最大，就得到全局最优。

### 示例演算

数组 `[1,2,3,2,4,1]`：值 `2` 的端点为下标 2 和 4，可删除 1 个；值 `1` 的端点为下标 1 和 6，可删除中间 4 个，所以答案为 4。若数组所有元素不同，哈希表从不产生候选，答案保持 0。

### 算法步骤

1. 初始化空哈希表 `first` 和 `ans=0`。
2. 从左到右扫描 1 基下标 `i` 和数值 `a_i`。
3. 若该值未出现，记录 `first[a_i]=i`。
4. 否则用 `i-first[a_i]-1` 更新 `ans`，且不要覆盖首次位置。
5. 输出 `ans`。

### 实现注意

- 删除区间不包含两个相等端点，所以公式必须减 1。
- 相等元素相邻时候选为 0，是合法但没有收益的操作；“最多一次”允许最终不操作。
- `a_i<=10^9`，可用哈希表；也可先离散化，但没有必要。
- 下标差在本题范围内普通整数足够。

### 复杂度

- 哈希表期望时间 `O(n)`，最坏取决于实现；`n<=200000`。
- 空间复杂度 `O(u)`，`u` 为不同数值个数，最坏 `O(n)`。

## q02：小红的项链

题目链接：[小红的项链](https://www.nowcoder.com/questionTerminal/3da065cab096478eb603bbfca5af8b02)

### 题意转化与关键观察

排序三个红珠位置 `p1<p2<p3`，把环切成间距 `g1=p2-p1、g2=p3-p2、g3=n-p3+p1`。任意两颗红珠的最短距离至少为 `k`，充要条件是这三个相邻红珠间距都至少为 `k`：任何不足间距会直接使其两端违规；三段都足够时，另一方向由至少两段组成，也不会更短于 `k`。

### 从移动到缺口和

红珠与相邻白珠交换一次，会让相邻的一个间距加 1、另一个减 1。因此是在三个间距之间搬运单位长度。总间距固定为 `n`，若 `n<3k` 必然无解。

可行时，间距 `g` 需要补 `max(0,k-g)` 个单位。每次交换最多补一个单位，所以缺口和是下界。由于总盈余至少等于总缺口，且三个间距两两可通过共同红珠直接转移单位，逐个从盈余段补到不足段即可在恰好缺口和次交换内完成。

### 正确性说明

总和条件证明不可行情形。对可行情形，任何方案必须为每个缺失单位付出一次交换；搬运构造又达到该次数。故

`ans=sum(max(0,k-g_i))`

既是下界也是可达值，必为最优。

### 示例演算

`n=12,k=3`、位置 `1,3,9` 给出间距 `[2,6,4]`。把位置 3 的红珠向顺时针方向移动一格，相当于从第二段取 1 补第一段，得到 `[3,5,4]`，答案为 1。若 `n=8,k=3`，三段至少需要总长 9，输出 `-1`。

### 算法步骤

1. 对三个位置排序。
2. 计算两个线性间距和一个跨首尾间距。
3. 若 `n<3*k`，输出 `-1`。
4. 否则累加三个 `max(0,k-gap)` 并输出。

### 实现注意

- 跨首尾间距是 `n-p3+p1`。
- 三个位置互异，所以初始间距至少为 1；移动构造也不会让红珠重合。
- `3*k` 和答案用 64 位，避免 `10^9` 量级乘法溢出。
- 已满足条件时输出 0。

### 复杂度

- 每组时间 `O(1)`、额外空间 `O(1)`；排序三个数也视为常数。

## q03：小红玩纸牌

题目链接：[小红玩纸牌](https://www.nowcoder.com/questionTerminal/41bdac26deca40edbbffaf14203144e8)

### 题意转化与关键观察

同花顺只在同一花色内消耗五个连续牌值各一张。先按花色拆开，再由缺失牌值把每种花色拆成连续段，各部分没有资源共享。连续段内从最小起点向右贪心，并按数量批量扣牌。

### 贪心转移的推导

处理起点 `v` 时，能取的最大套数是窗口剩余数量最小值

`t=min(cnt[v..v+4])`。

牌值 `v` 不会被任何起点更大的未来顺子使用，所以当前窗口是它最后的利用机会。若某个最优方案比贪心少取一套，释放的牌只能帮助起点 `v+1..v+4` 的顺子；这些未来窗口全部包含 `v+4`，而少取一套只释放一张 `v+4`，最多换回一套，不会得到更大总数。于是可把最优方案调整为当前取满而不变差。

### 正确性说明

按起点从左到右使用上述交换论证，可以逐步让某个最优方案与贪心前缀一致，直至整个连续段一致，因此段内贪心最优。不同连续段与花色完全独立，答案相加仍是全局最优。

### 示例演算

某花色牌值 `10..14` 数量为 `[3,2,4,2,5]`，窗口最小值为 2，可以一次取两套，剩余 `[1,0,2,0,3]`，再无完整窗口，贡献 2。批量扣减与逐副拿牌结果相同，但不会受 `10^9` 数量上界影响。

### 算法步骤

1. 按花色收集记录并按牌值升序排序。
2. 按相邻牌值差是否为 1 分成连续段。
3. 对段内每个长度 5 窗口起点，求五个剩余计数的最小值 `t`。
4. 答案加 `t`，窗口五项各减 `t`。
5. 汇总四种花色并输出。

### 实现注意

- 牌值范围大，不能开到最大牌值的稠密数组；只存输入记录。
- 相同牌型允许多次，必须保留并批量使用 `cnt_i`。
- 一个记录最多参与五个窗口，直接查看五项仍是线性扫描。
- 答案和数量用 64 位整数。

### 复杂度

- 时间复杂度 `O(n log n)`（排序）加 `O(n)`（固定窗口扫描）。
- 空间复杂度 `O(n)`。

## q04：小红的好数组

题目链接：[小红的好数组](https://www.nowcoder.com/questionTerminal/9a18a92ffe02479a99ef6f30070b1dc4)

### 题意转化与关键观察

固定最终唯一异常位置 `j` 和其余位置的公共值 `x`。其余元素改到 `x` 的代价是绝对偏差和；若异常元素原值不等于 `x`，可保持不动，否则至少再改 1，故

\[
cost(j,x)=\sum_{i\ne j}|a_i-x|+[a_j=x]。
\]

需要枚举异常项，但每次不能线性重算剩余数组。

### 中位数与前缀和推导

删除 `j` 后，绝对偏差和在剩余 `n-1` 个数的中位数区间最小。排序数组并建立前缀和，只需取得删除后的下、上中位数两个候选。设候选 `x=b[r]`，下标从 0 开始，`P[t]` 为排序数组前 `t` 项之和，则

    left  = x*r - P[r]
    right = (P[n]-P[r+1]) - x*(n-r-1)
    allDist = left + right

`allDist` 是全数组到 `x` 的距离，再减去异常元素的 `|b[j]-x|` 就得到其余元素的基础代价。相等值落在 `r` 左右都贡献 0，因此直接使用候选所在下标即可。

额外的 `[a_j=x]` 不会把最优点推到候选之外：若中位区间有另一个端点不同于 `a_j`，选它即可免罚；若区间退化为 `a_j`，离开中位点会使基础凸函数至少增加 1，不优于直接支付 1。

### 正确性说明

枚举异常位置覆盖所有目标结构。对固定位置，绝对值和的中位数定理给出基础代价最优区间；检查上下端点并加入异常碰撞代价即可取得该位置的最优值。所有位置取最小，得到全局最少操作数。

### 示例演算

- `[2,2,5,2]` 选择 5 为异常项、公共值 2，代价 0，原数组已经是好数组。
- `[3,3,3]` 的剩余中位数总是 3，基础代价 0，但异常项也等于 3，需要额外修改 1，答案为 1。
- `[1,2]` 已可视为一个元素异于其余单元素集合，答案 0；`[1,1]` 答案 1。

### 算法步骤

1. 排序数组并建立 64 位前缀和。
2. 枚举排序位置 `j` 为异常项。
3. 计算删除它后剩余序列的下、上中位排名；排名跨过 `j` 时映射下标加 1。
4. 对每个候选值，用前缀和求全体绝对距离并减去异常项距离。
5. 若异常值等于候选公共值，代价加 1；更新答案。
6. 输出全局最小值。

### 实现注意

- 剩余元素数为偶数时不要只检查一个中位端点。
- 距离和可达 `10^14`，使用 64 位整数。
- 候选值有重复时重复计算无害，也可去重。
- 异常项碰撞时改成相邻整数即可，额外代价确为 1。

### 复杂度

- 排序 `O(n log n)`，枚举与候选计算 `O(n)`；满足 `n<=10^5`。
- 空间复杂度 `O(n)`。
