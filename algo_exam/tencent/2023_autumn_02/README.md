## q01：小红的字符串生成

题目链接：[小红的字符串生成](https://www.nowcoder.com/questionTerminal/a607ec1b2f9849728f16fc9172322900)

### 题意转化与关键观察

构造过程中只能向末尾追加内容，所以任意时刻已经生成的字符串必然是目标 `t` 的一个前缀。可以按当前前缀长度做 DP。难点在复制操作：源子串必须在操作前的前缀中完整存在，内容要等于目标的下一段，而且不同源起点代表不同操作选择，必须分别计数。

### 从最后一步到 DP 转移

令 `dp[i]` 为生成 `t[0..i)` 的方式数，`dp[0]=1`。

- 单字符操作：追加唯一正确字符 `t[i]`，所以 `dp[i+1]+=dp[i]`。
- 复制操作：选择源起点 `j<i` 和长度 `len>=2`。合法条件是 `j+len<=i`（源在旧前缀内）、`i+len<=n`（目标不越界），且 `t[j..j+len)=t[i..i+len)`。

预处理 `lcp[x][y]` 表示后缀 `t[x:]、t[y:]` 的最长公共前缀，则固定 `(i,j)` 可复制的最大长度为

\[
limit=\min(lcp[j][i],\ i-j,\ n-i)。
\]

对每个 `len=2..limit` 都有一次独立操作，使 `dp[i+len]+=dp[i]`。

### 二次复杂度优化

直接枚举 `i,j,len` 是 `O(n^3)`，`n=300` 虽可能勉强实现，但可自然优化。对固定 `i` 建差分数组：每个源 `j` 若 `limit>=2`，就在复制长度区间 `[2,limit]` 上加 1，即 `diff[2]++、diff[limit+1]--`。对长度做前缀和后得到 `sourceCount[len]`，表示该长度有多少个合法源位置，再统一转移

`dp[i+len] += dp[i]*sourceCount[len]`。

### 正确性说明

任意生成方案的最后一次操作唯一属于两类：追加单字符，或从某个确定的源起点复制确定长度。删去最后一步后必然是某个前缀状态 `dp[i]`；上述条件恰好判定该最后一步是否合法，因此所有方案都会被计入。反过来，每个转移的源完全位于旧前缀且内容匹配目标下一段，执行后仍得到目标前缀。源起点不同即操作选择不同，差分统计保留了其数量，故无遗漏、无误合并。

### 状态演算：`t=aaaaa`

当已生成长度 `i=3` 的 `aaa` 时，目标还剩 `aa`。长度 2 的源既可以选位置 `j=0` 的 `aa`，也可以选 `j=1` 的 `aa`；二者内容相同但位置不同，所以 `sourceCount[2]=2`，从 `dp[3]` 向 `dp[5]` 贡献 `2*dp[3]`。这说明不能只判断“该字符串是否出现过”。

### 算法步骤

1. 从右下向左上预处理 `lcp`：字符相同则 `lcp[x][y]=1+lcp[x+1][y+1]`，否则为 0。
2. 初始化 `dp[0]=1`，其余为 0。
3. 按 `i=0..n-1` 扫描，先做单字符转移到 `i+1`。
4. 清空当前长度差分数组；枚举所有源起点 `j<i`，计算 `limit`，把 `[2,limit]` 加 1。
5. 对差分求前缀和，得到每个复制长度的合法源数。
6. 对 `len=2..n-i`，更新 `dp[i+len] += dp[i]*sourceCount[len]`。
7. 全程取模，输出 `dp[n]`。

### 实现注意

- 源不能覆盖本次尚未生成的字符，`i-j` 这一上界不可漏。
- 复制长度至少为 2；长度 1 只能由第一种操作完成。
- 同内容、不同源位置必须分别计数。
- `lcp` 用整数即可；`dp`、差分前缀和的乘积先用 64 位，再对 `10^9+7` 取模。

### 复杂度

- 时间复杂度：预处理 LCP `O(n^2)`，所有差分统计与 DP 转移合计 `O(n^2)`；适合 `n<=300`。
- 空间复杂度：`O(n^2)` 保存 LCP，DP 与临时差分为 `O(n)`。

## q02：小红的二叉树拼接

题目链接：[小红的二叉树拼接](https://www.nowcoder.com/questionTerminal/d11ea70ceaf2437d89f2695c7e48606b)

### 题意转化与关键观察

设第 `i` 棵树高度为 `h_i`、最深叶子数为 `c_i`。把下一棵树接到当前树的最深叶子上，最终最长路径会增加下一棵树的高度；该叶子的左、右孩子都为空，所以连接方向还有 2 种。

能达到的高度上界是所有原树高度之和。要达到它，所有树都必须依次出现在同一条最深链上：若某棵树接在最长链之外，它的高度就没有被累加到最终最长路径，上界不可能取到。因此最大高度方案必然是把 `n` 棵树排成一个有序链。

### 从链结构到计数公式

若树 `i` 不是链底最后一棵，它需要选择一个最深叶子和左/右方向，共

\[
y_i=2c_i
\]

种连接选择；链底树不再向下连接，不贡献该因子。

固定树 `L` 为链底后，其余 `n-1` 棵树在上方有 `(n-1)!` 种排列，连接选择数为 `prod(i!=L)y_i`。所以

\[
ans=(n-1)!\sum_{L=1}^{n}\prod_{i\ne L}y_i \pmod{10^9+7}。
\]

排除一个因子的乘积可用前缀积和后缀积求出，无需做模除法。

### 如何求每棵树的最深叶子数

对每棵二叉树后序遍历，每个节点返回 `(height,count)`：

- 叶子返回 `(1,1)`；
- 只有一个孩子时，高度为孩子高度加 1，计数继承该孩子；
- 两个孩子高度不同，取更深孩子的计数；高度相同，则最深叶子来自两侧，计数相加。

节点权值随机使原树可区分，题目所说的不同拼接方式可按树顺序、叶子选择和左右选择分别计数。

### 正确性说明

任意根到叶路径经过每棵原树时最多贡献该树高度，所以最终高度不超过 `sum(h_i)`；逐棵接到当前最深叶子的链构造达到该值。若达到上界，每棵树都必须位于某条最长链，故方案必然可唯一描述为一个树排列、每个非末树的最深叶子选择及左右方向。公式恰好枚举这些独立选择，既不漏也不重。

### 示例演算

假设三棵树的最深叶子数为 `c=[1,2,1]`，则 `y=[2,4,2]`。

- 第 1 棵作链底：连接选择为 `4*2=8`；
- 第 2 棵作链底：为 `2*2=4`；
- 第 3 棵作链底：为 `2*4=8`。

底树选择合计 `20`，其余两棵的上下顺序有 `2!` 种，总答案为 `40`。

### 算法步骤

1. 对每棵输入树做后序遍历，求最深叶子数 `c_i`，令 `y_i=2*c_i mod MOD`。
2. 预处理 `prefix[i]` 为 `y_0..y_{i-1}` 的积，`suffix[i]` 为 `y_i..y_{n-1}` 的积。
3. 对每个链底 `i`，排除积为 `prefix[i]*suffix[i+1]`，累加得到 `sumExclude`。
4. 计算 `(n-1)! mod MOD`。
5. 输出 `factorial*sumExclude mod MOD`。

### 实现注意

- 链底不需要选择叶子或左右方向，不能多乘一次 `2c_i`。
- `n=1` 时排除积为空积 1，`0!=1`，答案应为 1。
- 所有树节点总数 `S<=200000`，深链递归可能栈溢出，优先使用显式栈生成后序。
- 叶子计数、乘积与阶乘都要取模；结构高度只用于比较，可用普通整数。

### 复杂度

- 时间复杂度：遍历所有树 `O(S)`，前后缀积和阶乘 `O(n)`，总计 `O(S+n)`。
- 空间复杂度：`O(S+n)`，用于树结构、遍历栈和计数数组。

## q03：小红的数位删除

题目链接：[小红的数位删除](https://www.nowcoder.com/questionTerminal/e65181c848a746cda2600326fe4a34ba)

### 题意转化与关键观察

删除数位只会保留原数位的相对顺序。一个非空十进制整数是 5 的倍数，当且仅当末位为 `0` 或 `5`。因此只需决定保留原串中的哪一个 `0/5` 作为新末位；它右边的所有数位必须删除，而它左边的数位全部保留不会破坏整除性。

### 从必要条件到最优策略

若选择下标 `i` 的 `0/5` 作为末位，至少要删除其右侧 `d-1-i` 个数位；删除左侧任何数位都不是必要的，只会增加操作数。因此该选择的最优代价就是右侧长度。

要让代价最小，应选最靠右的 `0` 或 `5`。若整个数字中都没有这两种数位，则任何非空子序列都不可能是 5 的倍数，只能按题意删除所有 `d` 位得到 `0`。

### 正确性说明

任意非空合法结果的最后一位必来自原数的某个 `0/5`，且原来位于它右侧的数位若保留就会排在其后，所以这些数位全部必须删除，形成一个不可突破的下界。算法选择最右候选并只删除其右侧，恰好达到该下界。没有候选时，题面保证删空得到 0 合法，因此删 `d` 次最优。

### 示例演算

- `n=1234567`：最右的候选是数字 `5`，其后有 `6,7` 两位；删除后得到 `12345`，答案为 2。
- `n=12050`：末位已经是 `0`，无需操作，答案为 0。
- `n=137`：没有 `0/5`，只能删空，答案为 3。

### 算法步骤

1. 把数字按十进制字符串处理，长度记为 `d`。
2. 从下标 `d-1` 向左扫描。
3. 遇到第一个字符 `'0'` 或 `'5'`，输出其右侧字符数 `d-1-i` 并结束。
4. 若扫描结束仍未找到，输出 `d`。

### 实现注意

- 原数已是 5 的倍数时必须返回 0。
- 不需要实际执行删除或构造结果。
- 删除全部数位得到 0 是题面的特殊约定，所以“无候选”不是无解。
- `n<=10^9` 只有至多 10 位，整数取模扫描或字符串扫描都可以；字符串写法更直观。

### 复杂度

- 时间复杂度：`O(d)`，`d` 为十进制位数，本题至多 10。
- 空间复杂度：若使用字符串为 `O(d)`；仅用整数逐位处理可做到 `O(1)`。
